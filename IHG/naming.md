# 用語と名づけ

**名づけはもう `DEM/local_ai/` の常駐ループだけが行う。** Claude が対話の
中でこの手順を踏んで直接名づけることはしない。このファイルは、なぜその
基準にしたかの設計根拠であり、`IHG/ai_instructions/naming.py`(常駐ループの
プロンプトに埋め込む要旨版の定数)の**正本**である。**この節の基準を
変えたら、`naming.py` も合わせて直す。**

## 読者

**日本人。** 日本語のラノベとして自然に読めることを最優先する。
設定資料として正確な語より、本文に置いて浮かない語を選ぶ。

## 設定側の名と、作中の名を分ける

**設定側**(場所・個体・人物・語のレコード)と**本文側**(話の原稿)では、
名づけの基準が逆になる。**先にどちら側の名かを決める。**

|        | 基準                                                        | 例                                                 |
| ------ | ----------------------------------------------------------- | -------------------------------------------------- |
| 設定側 | **現代から見て具体的・論理的。** 何が起きたかが名前で分かる | 現代科学先端時代、崩壊時代、西暦 3630 年の軌道事故 |
| 本文側 | **作中の人間が呼んでいる名。** このファイルの以降の節に従う | 白い年                                             |

理由は三つ。

- **時代の呼び名は後世が決める。** 同じ時代を、星ごと・作品ごとに違う名で呼んでよい。
  設定側に作中の呼び名を置くと、作品が増えるたびに書き換えることになる
- **年代は西暦(またはその世界の基準暦)で通す。** 作中で別の暦を使うのは自由だが、
  記録の側の年表は一本に統一する。暦が二つあると、星をまたいだ時系列の照合ができない
- **設定側は音読み漢語でよい。** 「〜時代」「〜事故」のような分析用の札は読者に見せない。
  **本文に出す語だけが、このファイルの基準に縛られる**

ただし、**当時の人間が使っていた語は作中の名**である。制度・技術・組織の名は、
設定資料に書くときも以降の節に従って作る。
分けるのは「時代の札」と「当時の語」であって、設定資料と本文ではない。

作中の呼び名を思いついたら捨てずに、**語として控えておく。** `term` の
`kind` に「後世の呼び名」のような札を置き、まだどの作品も採っていないことが
`text` から分かるように書く(**語を db へ確定する入口はまだ無い**ので、
必要になったら `DEM/claude_interface/readme.md`「作り方」に沿って足すか、作者に相談する)。
断面が伏せるのは出来事の `裏` `伏線` だけで、**語には絞り込みが効かない**
(chronicle.md「断面に出さない種別」)。どの作品がどの名を採るかは、
その作品(`story`)の側で決める。

## 正式名称と通称をペアで作る

**制度・組織・技術には、名前を二つ与える。** 片方だけだと必ずどちらかで無理が出る。

|              | 誰がつけたか       | 縛り                                              | 本文での扱い                                     |
| ------------ | ------------------ | ------------------------------------------------- | ------------------------------------------------ |
| **正式名称** | 作った側・書類の側 | **音読み漢語・英語の頭字語で可。** 硬くてよい     | 原則出さない。出すのは看板・書類・皮肉のときだけ |
| **通称**     | 使う側・暮らす側   | **このファイルの以降の節に従う。** 和語かひらがな | こちらを使う                                     |

例:

| 対象             | 正式名称                                                                   | 通称     |
| ---------------- | -------------------------------------------------------------------------- | -------- |
| 発電の仕組み     | Heliotropic Integrated Network for Autotrophic Transduction and Allocation | ひなた   |
| 配分を決める組織 | 再配分機構                                                                 | さいはい |
| 人口政策         | 定員適正化計画                                                             | 数合わせ |

**通称は、正式名称から自然に落ちる形にする。** 思いつきで別の語を当てない。

- 頭字語を読む(H.I.N.A.T.A. → ひなた)
- 前を削る、後ろを削る(再配分機構 → さいはい)
- 中身を言い換える(定員に数を合わせる → 数合わせ)

**正式名称が硬いほど、通称は無害な顔をする。** そこに落差が出る。
「定員適正化計画」を「数合わせ」と呼びはじめた時点で、その社会はもう慣れている。

## 設定側でも、学術語より一般語を選ぶ

正式名称は硬くてよいが、**硬さと専門性は別物**である。
「その分野の人しか使わない語」は、設定資料でも避ける。読み返すのは作者だからだ。

| 使わない     | 使う     | なぜ                                     |
| ------------ | -------- | ---------------------------------------- |
| 陸塊         | 大陸     | 地質学の語。一語のまま、より通る語がある |
| 可動部       | 手足     | 機械の語。生き物に当てると急に硬くなる   |
| 群落         | 森、一帯 | 植物学の語                               |
| 設計耐用年数 | 耐用年数 | 短くして通じるなら短いほうを採る         |

**ただし、言い換えて長く・ぼんやりするなら、元の語を残す。**
カジュアルに寄せること自体が目的ではない。

| そのままでよい | 言い換えた場合               | 判断                                     |
| -------------- | ---------------------------- | ---------------------------------------- |
| 可住域         | 人の住める土地               | 長くなるだけ。**残す**                   |
| 自律単位       | 自分で考えて動かしている出先 | 間延びして、指すものがぼやける。**残す** |
| 接触面         | 触れるための面               | 一語で足りているので**残す**             |

### 判定は二段階

1. その語を、専門教育を受けていない大人が日常で使うか。使うならそのまま
2. 使わないなら、**一語のまま・より具体的に**置き換えられるか。
   置き換えられるなら替える。**できないなら元の語を残す**

**短くて、指すものがはっきりしているほうを採る。** それだけ。
開いた結果うすくなるくらいなら、専門語のほうがいい。

例外がもう一つある。**専門語であること自体が意味を持つ場合。**
「定員適正化計画」が硬いのは、硬い名前をつけた側の顔を見せるためである。
**硬さに理由があるなら残す。ないなら落とす。**

## 基準は三つ

| 種類             | 使いどころ                                          | 例                               |
| ---------------- | --------------------------------------------------- | -------------------------------- |
| **日本的な漢字** | 地形・組織・制度・道具。訓読み主体の和語            | 焼け跡、溜め池、見回り、寄り合い |
| **ひらがな**     | やわらかい語、月・祭礼・季節の名、口語、幼い呼び名  | はしり、なごり、ゆすり           |
| **カタカナ英語** | 技術・機械・外来の制度。SF 寄りの世界で比率を上げる | コード、ネジ、パイプ             |

一つの世界の中で三種類を混ぜてよい。**どの対象にどれを当てるかを決めて、最後まで守る。**

## 語の作り方(型)

新しい語は、思いつきではなく型に流し込んで作る。日本語にもとからある複合語の型を使えば、
初見でも意味が通り、読みでつっかえない。

| 型                   | 作り方                                   | 例                               |
| -------------------- | ---------------------------------------- | -------------------------------- |
| 動詞の連用形 ＋ 名詞 | 動作がそのまま名前になる。最も使いやすい | 焼け跡、割れ目、渡し場、預かり所 |
| 名詞 ＋ 名詞         | 素材・場所・性質を重ねる                 | 岩場、潮風、灰雲                 |
| 動詞の連用形だけ     | 動作を名詞にして抽象概念を作る           | 囲い、支え、隔て、繋ぎ           |
| 形容詞の語幹 ＋ 名詞 | 大小・深浅・新旧を含ませる               | 深場、細道、古道具               |
| 数詞 ＋ 和語         | 制度・集団の規模を出す                   | 三つ辻、七曲がり                 |
| カタカナ短縮         | 外来物。二〜四拍で切ると口に乗る         | コード、ネジ、パイプ             |

**迷ったら「動詞の連用形 ＋ 名詞」。** 日本語の地名・職名の多くがこの型で、失敗しにくい。

## 対象ごとの当て方

| 対象                                 | 当てるもの                                             | 例                             |
| ------------------------------------ | ------------------------------------------------------ | ------------------------------ |
| 地形(固有名詞ではない場所の種類)     | 訓読みの漢字。地形＋状態                               | 焼け野、川下、二股             |
| 地名(大陸・国・町・村などの固有名詞) | カタカナ。作り方は「固有名詞の作り方」に従う           | ヴォルホフ、トゥライ、ミグラ   |
| 組織・機関                           | 場所名か役割名で止める。「〜機構」「〜管理局」にしない | 記録所、見回り、寄り合い       |
| 制度・掟                             | 動詞の連用形。禁止なら「〜止め」「〜割り」             | 口止め、割り当て、立ち入り止め |
| 技術・処置                           | 短い和語かカタカナ。作用を一語で                       | 継ぎ、締め、コード             |
| 道具・機械                           | 用途をそのまま。古いものは和語、新しいものはカタカナ   | 古道具、カラクリ、ハシゴ       |
| 身分・階層                           | 「〜人」「〜衆」「〜の民」                             | 川人、若衆、山の民             |
| 現象・災害                           | 起きたことを名詞化。大げさな漢語にしない               | 地鳴り、大水、引き潮           |

同じ対象には同じ型を使う。組織を一つ「〜所」にしたら、他の組織も「〜所」「〜場」で揃える。
**型が揺れると、読者は同じ種類のものだと認識できない。**

## 避けるもの

**音読み二字熟語の造語を重ねない。** これをやると中華風・古典中国風に寄る。

| だめ(音読み造語)         | なおす         |
| ------------------------ | -------------- |
| 記録管理機構             | 記録所         |
| 統括評議会               | 寄り合い       |
| 巡回警備隊               | 見回り         |
| 貯水施設                 | 溜め池         |
| 遮蔽障壁                 | 囲い、壁       |
| 高温地帯(こうおんちたい) | 焼け野(やけの) |
| 延命処置(えんめいしょち) | 延べ(のべ)     |
| 起源音(きげんおん)       | 元音(もとね)   |

- 存在しない漢語をひねり出さない。**訓読みに開けないか必ず試す**
- ルビがなければ読めない字を使わない
- 四字以上の漢語(〜管理機構、〜自治圏、〜統制局)は**通称には使わない**。
  **正式名称としてなら使ってよい**(→「正式名称と通称をペアで作る」)
- 同じ音読み造語を組み合わせて別語を作らない(一つ許すと連鎖する)

## 例外

日本語としてすでに定着している音読み語は普通に使ってよい。

> 記録、地図、儀式、条約、都市、国境、階級、装置、信号

**問題なのは造語のほう。** 既存語はむしろ積極的に使う。
既存語で足りるなら新語を作らない。**新語は、既存語では指せないものにだけ与える。**

## 判定のしかた

作った語は四つとも通す。一つでも引っかかったら作り直す。

1. **声に出して読めるか。** つっかえたら直す
2. **日本のラノベの目次に並んでいて浮かないか**
3. **訓読みに開けないか。** 開けるなら開く
4. **同じ作品の他の語と紛れないか。** 頭の音・拍数が近い語は片方を変える

決めた語は `term` のレコードとして残す。
**上位の語にぶら下がるなら `parent_term_id` で吊る**(魔力 → 魔力切れ)。
既にある語は `SearchTerms(<キーワード>)` で探す。表記ゆれは設定の破綻と同じ扱い。

**語の届く範囲(`restrict_*`)は空でよい。** どこまで届いている語かは、
話が進んでから決まる。
**国・組織のような「群」は語ではない。** 語として残すのは呼び名であって、
振る舞いを持つものは個体(`object`)の側に置く(chronicle.md)。

## ジャンルごとの使い分け

地球の歴史・地理・文化を下敷きにする。そのほうが読者に通じ、構成も立てやすい。
中国・日本・ヨーロッパ・アメリカは特に馴染みが深いが、参照先は全世界に広げてよい。

**配合をジャンルごとに決めてから語を作る。**

### 日本的 SF

近未来から未来の日本。AI・サイボーグ・VR・情報技術が発展しつつある世界。

|              | 配合                             |
| ------------ | -------------------------------- |
| 漢字(訓読み) | 5 割。地名・組織・身分・古い制度 |
| カタカナ英語 | 4 割。技術・機械・新しい制度     |
| ひらがな     | 1 割。俗称・口語                 |

技術側をカタカナ、生活側を和語にすると、新旧の層が自然に分かれる。

### 中世ヨーロッパファンタジー

中世ヨーロッパの地理・文化がベース。

|              | 配合                         |
| ------------ | ---------------------------- |
| カタカナ     | 7 割。人名・地名・組織・階級 |
| 漢字(訓読み) | 2 割。地形・生活道具         |
| ひらがな     | 1 割。祭礼・愛称             |

カタカナは実在の言語の音を借りる。綴りから作るより、音から作るほうが読みやすい。

## 固有名詞の作り方(乱数に通す)

国名・種族名・大陸名・町や村の名など、場所の固有名詞は思いつきで作らない。**手順に流す。**
**設定側と本文側で名を分けない。** どちらもここで作ったカタカナ一本で通す。

**例外: 地球の大陸は現代の地理を再現する。** 地球は架空の星ではないので、
この手順(乱数で言語を引いてカタカナを作る)を通さない。アジア・アフリカ・
北アメリカ・南アメリカ・オーストラリア・南極・ヨーロッパのような、現実の
大陸名をそのまま使う。地球の下に置く場所のうち、大陸より下の階層(国・町・
村など)も同様に、実在の地理・地名を土台にする。

1. **意味を決める。** その国・土地の地理と文化を一言で
2. 古めの漢字二字で、意味をいったん言い切ってみる。**これは思考の踏み台であり、ファイルには残さない**
3. **言語を一つ引く。** 本来は `DEM/randomizer/roll.py` の「名づけ/言語」を
   引くが、**引く先の `tables.json` が無く現状は動かない。** 直すまでは
   `random` で言語を選び、**選んだ言語とシードを会話に残す**
4. 引いた言語で、その意味を**端的に言う**。一語か、一語に縮めた複合語
5. **カタカナにする。** 三〜五拍。読んでつっかえたら、同じ意味の別の語に取り替える
6. できたカタカナを、そのまま場所の `name` にする。
   国・組織など別のレコードを持つものは、そちらも同じカタカナで揃える

### なぜ言語を引くのか

放っておくと、**人も AI も同じ音の並びばかり作る。**
引いた言語の音韻が、想像の外から形を連れてくる。
「どの言語が出たか」ではなく、「その音で何ができたか」が名前になる。

### 守ること

- **頭の音を揃えない。** 同じ物語に出る名は、頭の一拍を互いに変える
- **拍数も散らす。** 三拍ばかり並べない
- 音が合わないときは**語を取り替える。言語は引き直さない**
- 引いた言語とシードは会話に残す(db に置き場所がまだ無い)

### 例

| 意味                       | 漢字二字(踏み台) | 引いた言語   | 名                         |
| -------------------------- | ---------------- | ------------ | -------------------------- |
| 湿地と森。術者が治める     | 澤巫             | ロシア語     | **ヴォルホフ**(大陸・国)   |
| 塩の平原。征服された民     | 鹽軛             | ラトビア語   | **サールゼメ**(大陸・国)   |
| 霧の低地。商人が仕切る     | 霧湊             | アルメニア語 | **ムシュヴァン**(大陸・国) |
| 内海に面した荷の集散地。町 | 荷揚             | タミル語     | **トゥライ**(町)           |
| 霧が降りる、森の裾の村     | 霧降             | リトアニア語 | **ミグラ**(村)             |

## 人名

日本人に馴染みのある形を基本にする。**漢字の氏名**か、**カタカナの氏名**のどちらかを土台に置く。

`DEM/local_ai/time_keeper/random_character_generator.py` が
`IHG/ai_instructions/naming.py` の `CHARACTER_NAMING_INSTRUCTION` を使って
人名を決める。下の指針は、その定数を書く・見直すときの根拠にする。

- 文化ごとの命名規則(氏名の順序、父称、通り名)を反映させてよい。雰囲気が出る
- ただし**独自性を出しすぎない。** 読めない・覚えられない名前は、それだけで読者が離れる
- 主要人物ほど短く。三〜五拍で呼べる名にする
- 同じ作品内で頭の音が重ならないようにする
- 呼び分け(苗字・名・愛称・役職)を決めておくと、話者と距離感を地の文なしで示せる
