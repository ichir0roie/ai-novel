# novels

**世界の記録と、本文。** 置き場所がレコードの種類を決める。
読み方と書き方は chronicle.md、進め方は workflow.md。

```
novels/
  worlds/<世界線>/                 場所の木。**1 ディレクトリ = 1 世界線**
    <世界線>.md                    いちばん外の場所（暦・共通現象・絶対規則）
    rolls.md                       乱数ログ。引いた目とシード、調整の理由
    glossary.md                    用語索引。**自動生成。手で書かない**
    <星>/
      <星>.md                      場所のレコード
      history.md  society.md       自由文書。読み物として置いてよい
      events/{時刻}_{名}.md        出来事・指標・関係・火種
      <地域>/<地域>.md             さらに内側の場所
  objects/<世界線>/                **群として振る舞うもの**
    <種別>.md                      種別（系統・国・組織・仕組み）
    **/<個体>/                     個体（種族・国・組織など、名前のある群）
      <個体>.md                    個体のレコード
      places/{時刻}_{場所}.md      居場所の推移
      actions/{時刻}_{名}.md       行動。**動機と代償と結果をそろえて**
  characters/<出身地>/**/<人名>/   **一人ひとりの人間**
    <人名>.md                      人物のレコード。いちばん細かい
    places/{時刻}_{場所}.md        居場所の推移
    actions/{時刻}_{名}.md         行動。**動機と代償と結果をそろえて**
  terms/**/<語>/<語>.md            語。入れ子にできる（上位の語にぶら下がる）
  stories/<作品名>/                本文
    meta.md  plot.md  episodes/<話数>.md
  novel.db                         組み上げた SQLite。git には入れない
```

## 置き場所の決まり

- **ディレクトリ名と同じ名前の md だけが、その場所のレコード。**
  それ以外の md は自由文書として読み飛ばされる
- **`{時刻}` は `yyyymmddhhmmss`。** 頭から欠けた分は書かなくてよい（`4360` でよい）
- **id を書かなければファイル名が id になる。**
  他から指されるもの（出来事）だけ短い id を front matter に書く
- **入れ子が所属を表す。** `ムシュヴァン/商人組合/` で所属が構造になる
- **群と個人を混ぜない。** 「魔族は追われる」は `objects/`、
  「その魔族の娘が何を思ったか」は `characters/`

## 原則

- **物語に必要な分だけ作る。** 使われない設定は書かないほうがいい
- **制限を書く。** 能力には必ず代償か制限を設ける。制限のない設定は物語を殺す
- **同じ世界線の中では矛盾を許さない。** 暦・物理法則・共通現象は星をまたいで一致させる
- **世界線どうしの矛盾は平行世界として許容する。** 別の `worlds/<世界線>/` は直さない
- **作品は世界線をまたがない。** またぎたくなったら、それは別の作品である
- **本文で生まれた設定は必ず戻す。** 手順は workflow.md「3 世界観更新モード」
- **文章が正、記録が従。** 食い違ったら文章を先に直す。
  **記録にしか存在しない設定を作らない**
- **`glossary.md` を手で書かない。** 語を足すときは `terms/` にファイルを作り、
  `python3 tools/novel.py index --world <世界線>` で作り直す
- **名づけは日本語として自然に。** 音読み二字熟語の造語を重ねない（naming.md）
- **アバウトな要素は乱数で決める。** `tools/roll.py`。引いた目は `rolls.md` に全部残す
