# 用語と名づけ

## 読者

**日本人。** 日本語のラノベとして自然に読めることを最優先する。
設定資料として正確な語より、本文に置いて浮かない語を選ぶ。

## 設定側の名と、作中の名を分ける

`worlds/` と `stories/` では、名づけの基準が逆になる。**先にどちら側の名かを決める。**

| | 基準 | 例 |
| --- | --- | --- |
| `worlds/` | **現代から見て具体的・論理的。** 何が起きたかが名前で分かる | 現代科学先端時代、崩壊時代、西暦 3630 年の軌道事故 |
| `stories/` | **作中の人間が呼んでいる名。** このファイルの以降の節に従う | 白い年 |

理由は三つ。

- **時代の呼び名は後世が決める。** 同じ時代を、星ごと・作品ごとに違う名で呼んでよい。
  設定側に作中の呼び名を置くと、作品が増えるたびに書き換えることになる
- **年代は西暦（またはその世界の基準暦）で通す。** 作中で別の暦を使うのは自由だが、
  `worlds/` の年表は一本に統一する。暦が二つあると、星をまたいだ時系列の照合ができない
- **設定側は音読み漢語でよい。** 「〜時代」「〜事故」のような分析用の札は読者に見せない。
  **本文に出す語だけが、このファイルの基準に縛られる**

ただし、**当時の人間が使っていた語は作中の名**である。制度・技術・組織の名は、
設定資料に書くときも以降の節に従って作る（例: 継ぎ火、数合わせ、配り所）。
分けるのは「時代の札」と「当時の語」であって、設定資料と本文ではない。

作中の呼び名を思いついたら捨てずに、`glossary.md` の「後世の呼び名」に控えておく。
どの作品がどの名を採るかは、その作品の `meta.md` で決める。

## 基準は三つ

| 種類 | 使いどころ | 例 |
| --- | --- | --- |
| **日本的な漢字** | 地形・組織・制度・道具。訓読み主体の和語 | 焼け跡、溜め池、見回り、寄り合い |
| **ひらがな** | やわらかい語、月・祭礼・季節の名、口語、幼い呼び名 | はしり、なごり、ゆすり |
| **カタカナ英語** | 技術・機械・外来の制度。SF 寄りの世界で比率を上げる | コード、ネジ、パイプ |

一つの世界の中で三種類を混ぜてよい。**どの対象にどれを当てるかを決めて、最後まで守る。**

## 語の作り方（型）

新しい語は、思いつきではなく型に流し込んで作る。日本語にもとからある複合語の型を使えば、
初見でも意味が通り、読みでつっかえない。

| 型 | 作り方 | 例 |
| --- | --- | --- |
| 動詞の連用形 ＋ 名詞 | 動作がそのまま名前になる。最も使いやすい | 焼け跡、割れ目、渡し場、預かり所 |
| 名詞 ＋ 名詞 | 素材・場所・性質を重ねる | 岩場、潮風、灰雲 |
| 動詞の連用形だけ | 動作を名詞にして抽象概念を作る | 囲い、支え、隔て、繋ぎ |
| 形容詞の語幹 ＋ 名詞 | 大小・深浅・新旧を含ませる | 深場、細道、古道具 |
| 数詞 ＋ 和語 | 制度・集団の規模を出す | 三つ辻、七曲がり |
| カタカナ短縮 | 外来物。二〜四拍で切ると口に乗る | コード、ネジ、パイプ |

**迷ったら「動詞の連用形 ＋ 名詞」。** 日本語の地名・職名の多くがこの型で、失敗しにくい。

## 対象ごとの当て方

| 対象 | 当てるもの | 例 |
| --- | --- | --- |
| 地名・地形 | 訓読みの漢字。地形＋状態 | 焼け野、川下、二股 |
| 組織・機関 | 場所名か役割名で止める。「〜機構」「〜管理局」にしない | 記録所、見回り、寄り合い |
| 制度・掟 | 動詞の連用形。禁止なら「〜止め」「〜割り」 | 口止め、割り当て、立ち入り止め |
| 技術・処置 | 短い和語かカタカナ。作用を一語で | 継ぎ、締め、コード |
| 道具・機械 | 用途をそのまま。古いものは和語、新しいものはカタカナ | 古道具、カラクリ、ハシゴ |
| 身分・階層 | 「〜人」「〜衆」「〜の民」 | 川人、若衆、山の民 |
| 現象・災害 | 起きたことを名詞化。大げさな漢語にしない | 地鳴り、大水、引き潮 |

同じ対象には同じ型を使う。組織を一つ「〜所」にしたら、他の組織も「〜所」「〜場」で揃える。
**型が揺れると、読者は同じ種類のものだと認識できない。**

## 避けるもの

**音読み二字熟語の造語を重ねない。** これをやると中華風・古典中国風に寄る。

| だめ（音読み造語） | なおす |
| --- | --- |
| 記録管理機構 | 記録所 |
| 統括評議会 | 寄り合い |
| 巡回警備隊 | 見回り |
| 貯水施設 | 溜め池 |
| 遮蔽障壁 | 囲い、壁 |
| 高温地帯（こうおんちたい） | 焼け野（やけの） |
| 延命処置（えんめいしょち） | 延べ（のべ） |
| 起源音（きげんおん） | 元音（もとね） |

- 存在しない漢語をひねり出さない。**訓読みに開けないか必ず試す**
- ルビがなければ読めない字を使わない
- 四字以上の漢語（〜管理機構、〜自治圏、〜統制局）は組織名でも使わない
- 同じ音読み造語を組み合わせて別語を作らない（一つ許すと連鎖する）

## 例外

日本語としてすでに定着している音読み語は普通に使ってよい。

> 記録、地図、儀式、条約、都市、国境、階級、装置、信号

**問題なのは造語のほう。** 既存語はむしろ積極的に使う。
既存語で足りるなら新語を作らない。**新語は、既存語では指せないものにだけ与える。**

## 判定のしかた

作った語は四つとも通す。一つでも引っかかったら作り直す。

1. **声に出して読めるか。** つっかえたら直す
2. **日本のラノベの目次に並んでいて浮かないか**
3. **訓読みに開けないか。** 開けるなら開く
4. **同じ作品の他の語と紛れないか。** 頭の音・拍数が近い語は片方を変える

決めた語は必ず `worlds/<宇宙名>/glossary.md` に登録する。表記ゆれは設定の破綻と同じ扱い。

## ジャンルごとの使い分け

地球の歴史・地理・文化を下敷きにする。そのほうが読者に通じ、構成も立てやすい。
中国・日本・ヨーロッパ・アメリカは特に馴染みが深いが、参照先は全世界に広げてよい。

**配合をジャンルごとに決めてから語を作る。**

### 日本的 SF

近未来から未来の日本。AI・サイボーグ・VR・情報技術が発展しつつある世界。

| | 配合 |
| --- | --- |
| 漢字（訓読み） | 5 割。地名・組織・身分・古い制度 |
| カタカナ英語 | 4 割。技術・機械・新しい制度 |
| ひらがな | 1 割。俗称・口語 |

技術側をカタカナ、生活側を和語にすると、新旧の層が自然に分かれる。

### 中世ヨーロッパファンタジー

中世ヨーロッパの地理・文化がベース。

| | 配合 |
| --- | --- |
| カタカナ | 7 割。人名・地名・組織・階級 |
| 漢字（訓読み） | 2 割。地形・生活道具 |
| ひらがな | 1 割。祭礼・愛称 |

カタカナは実在の言語の音を借りる。綴りから作るより、音から作るほうが読みやすい。

## 人名

日本人に馴染みのある形を基本にする。**漢字の氏名**か、**カタカナの氏名**のどちらかを土台に置く。

- 文化ごとの命名規則（氏名の順序、父称、通り名）を反映させてよい。雰囲気が出る
- ただし**独自性を出しすぎない。** 読めない・覚えられない名前は、それだけで読者が離れる
- 主要人物ほど短く。三〜五拍で呼べる名にする
- 同じ作品内で頭の音が重ならないようにする
- 呼び分け（苗字・名・愛称・役職）を決めておくと、話者と距離感を地の文なしで示せる
