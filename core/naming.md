# 用語と名づけ

## 読者

**日本人。** 日本語のラノベとして自然に読めることを最優先する。

## 基準は三つ

1. **日本的な漢字** —— 訓読み主体の和語。「焼け帯」「塩原」「寄り合い」「書き割り」
2. **ひらがな** —— やわらかい語、月や祭礼の名、口語
3. **カタカナ英語** —— SF 側の技術・制度・組織。「ボンド」「ハシゴ」

## 避けるもの

**音読み二字熟語の造語を重ねない。** これをやると中華風・古典中国風に寄る。

| だめ                       | なおす                 |
| -------------------------- | ---------------------- |
| 冠央信証機構               | 記録所                 |
| 焦帯（しょうたい）         | 焼け帯（やけおび）     |
| 継続処置・継続者・未継     | 延べ・延べ人・延べなし |
| 前技（ぜんぎ）             | 古仕掛け（ふるじかけ） |
| 十四合議（じゅうしごうぎ） | 十四の寄り合い         |
| 祖音（そおん）             | 元音（もとね）         |
| 大段（だいだん）           | 大棚（おおだな）       |

- 存在しない漢語をひねり出さない。**訓読みに開けないか必ず試す**
- ルビがなければ読めない字を使わない
- 四字以上の漢語（〜管理機構、〜自治圏）は組織名でも使わない

## 判定のしかた

1. **声に出して読めるか。** つっかえたら直す
2. **日本のラノベの目次に並んでいて浮かないか**
3. **訓読みに開けないか。** 開けるなら開く

## ジャンルごとの使い分け

共通事項として、地球の歴史、地理、文化は参考にして構成したほうが、理解しやすいだろうし、構成もしやすい。
個人的にわかりやすいのは、中国、日本、ヨーロッパ、アメリカではあるが、全世界の文化、歴史を参考に発展させたほうが良いだろう。

### サンプル1：日本的SF

近未来、未来の日本を想像した形。
AI,サイボーグ、VR、情報技術などが発展しつつある世界。
用語は日本的な漢字がおおく、半分程度英語圏由来のカタカナ英語も混じっている。

### サンプル2：中世ヨーロッパファンタジー

中世ヨーロッパの地理、文化をベースにして、カタカナ用語。

## 例外

日本語としてすでに定着している音読み語は普通に使ってよい（記録、地図、儀式、条約）。
**問題なのは造語のほう。** 既存語はむしろ積極的に使う。

## 人名

日本人に馴染みのある形をベースとするなら、漢字の氏名、英語のカタカナの氏名がベースになるだろう。
しかし、状況によっては、各文化の命名規則や雰囲気を表現してもいいと思う。
独自性を出しすぎても、良いことは無いかも。
