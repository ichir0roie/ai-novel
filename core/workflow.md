# 執筆ワークフロー

作業は**三つのモード**に分かれている。**一度に一つだけやる。**
混ぜると、設定を作りながら本文を書き、本文を書きながら設定を直すことになって、
どちらも中途半端に終わる。

```
  ┌──────────────┐   ┌──────────────┐   ┌──────────────┐
  │ 1 世界観構成  │ → │ 2 ストーリー  │ → │ 3 世界観更新  │
  │   モード      │   │   生成モード  │   │   モード      │
  └──────────────┘   └──────────────┘   └──────────────┘
         ↑                                      │
         └──────────────────────────────────────┘
   worlds / objects         stories            起きたことを
   / characters / terms      を書く             世界の側へ戻す
   を作る
```

1 は最初の一度だけ。**あとは 2 と 3 をひたすら回す。**

|                      | 読むもの                     | 書くもの                                       |
| -------------------- | ---------------------------- | ---------------------------------------------- |
| **1 世界観構成**     | `core/` と、あれば既存の世界 | `novels/worlds` `objects` `characters` `terms` |
| **2 ストーリー生成** | 断面（`brief`）              | `novels/stories`                               |
| **3 世界観更新**     | 書いた本文                   | `novels/worlds` `objects` `characters` `terms` |

**2 のあいだは世界の側を触らない。3 のあいだは本文を触らない。**
本文を書いている途中で設定を作りたくなったら、メモに書き出して 3 まで持ち越す。

置き場所の決まりは chronicle.md。形は `tools/schema.py` が決めている。

---

# 1 世界観構成モード

**`novels/worlds` `objects` `characters` `terms` を作るところまで。**
このモードでは `novels/stories` を一行も書かない。

## 1-1 企画を先に決める

細かい設定より先に、これだけ決める。設定から始めると、
**面白くない設定資料ができあがる。**

- **ログライン**: 「誰が、何を望み、何に阻まれる話か」を 1 文で
- **売り**: 読者が友達に説明するときの一言
- **読後感**: 読み終わったときにどんな気持ちでいてほしいか

## 1-2 世界を起こす

**物語に必要な分だけ作る。** 世界地図を全部埋める必要はない。
作るべきは「**主人公の行動を制限するルール**」と「**対立の火種**」。
制限のない世界では何も起きない。

作る順番はこれで固定する。**前を飛ばして後ろを作らない。**

| 順  | 何を                                 | どこに                                              |
| --- | ------------------------------------ | --------------------------------------------------- |
| 1   | **世界線**（いちばん外の場所）       | `novels/worlds/<世界線>/<世界線>.md`                |
| 2   | **星・大陸・地形**（場所の木）       | `novels/worlds/<世界線>/**/<場所>/<場所>.md`        |
| 3   | **種別**（系統・国・組織・仕組み）   | `novels/objects/<世界線>/<種別>.md`                 |
| 4   | **個体**（その種別の、名前のある群） | `novels/objects/<世界線>/**/<個体>/<個体>.md`       |
| 5   | **人物**（一人ひとりの人間）         | `novels/characters/<出身地>/**/<人名>/<人名>.md` |
| 6   | **出来事**（年表・指標・関係・火種） | `<場所>/events/{時刻}_{名}.md`                      |
| 7   | **語**                               | `novels/terms/**/<語>/<語>.md`                      |

**`terms/` は世界線でディレクトリを切らない。** どの世界線の語かは front matter の
`世界` が持つ。**`characters/` は世界線ではなく出身地で切る**（chronicle.md）。

**5 は作品が決まってから。** 世界だけ作るあいだ、人物は要らない。
群としての振る舞い（4）と、一人ひとりの中身（5）を混ぜない（chronicle.md）。

雛形は `python3 tools/novel.py template --kind 場所` で出る。

**既存の世界を使い回すなら、このモードは要らない。** 2 から始める。
一つの世界で何本も書けるのがこの構成の狙いである。

## 1-3 アバウトなところは乱数で決める

人口・年代・比率のように、設定から読めない数は `tools/roll.py` で振る。
**AI の第一想起で埋めない**（principles.md）。
引いた目とシードは `novels/worlds/<世界線>/rolls.md` に残す。

**例外は火種の値。** これは設定から読めるかどうかで決める。
読んで張っていないものは、まだ火種ではない。

## 1-4 締め

```
python3 tools/novel.py check                      # error 0 で終える
python3 tools/novel.py index --world <世界線>      # 用語索引を作り直す
```

# 2 ストーリー生成モード

**`novels/worlds` `objects` `characters` `terms` を元に、`novels/stories` を書く。**
このモードでは世界の側を一行も書き換えない。

## 2-1 プロット

- まず**結末**を決める。ゴールが決まっていないと道中が迷走する
- 次に**中間点**（主人公の目的や立場が反転する場面）を決める
- 最後に各話へ割る。1 話あたり「**山場ひとつ、引きひとつ**」

置き場所は `novels/stories/<作品名>/plot.md`。企画は `meta.md`。
`meta.md` には、**どの世界線のどの場所・どの年に立つか**を書く。

## 2-2 書く前に断面を取る

**設定ファイルを頭から読み直さない。** その話が立つ場所と年を決めて、
その時点の世界を一枚に出す。

```
python3 tools/novel.py brief --place 霧湊大陸 --time 4360
```

いま数がどちらへ動いているか、まだ終わっていない出来事は何か、
誰がその場にいて、何が張っているかが出る。
**3 節の「直近の出来事」は既定で 60 年ぶん。** もっと遡りたいときは
`--reach 200` のように伸ばす。

> **`--full` を付けない。** 付けると住人が知らないことまで出て、
> それを本文に書いてしまう。裏を設計するときだけ付ける。

断面の「その場にいる者」には、個体（群）と人物が並んで出る。
**その話で喋る人物は、断面のあとに一件ずつ読んでおく。**

```
python3 tools/novel.py show <人名>
```

一人称・二人称・三人称・口調がここにある。**本文の呼び方はこれに従う。**
書きながら決め直さない。決め直したくなったら、それはモード 3 の仕事である。

## 2-3 本文

`novels/stories/<作品名>/episodes/NNN.md`。**1 話 1 ファイル**、3 桁ゼロ埋め。

書きはじめる前に、その話の中で**変化するもの**を 1 つ確認する。
関係・情報・状況のいずれかが動かない話は、**削れる話**である。

- 書く順番は場面の頭から順に。難しい場面を飛ばして後から埋めない
  （前後のテンションが合わなくなる）
- **要約で済ませない。** 「〜という展開があった」で流さず、場面として書く
- **数を本文に出さない。** 台帳の数は作者だけが見る（chronicle.md）
- 途中で新しい設定が生まれたら、**本文にだけ書いて、メモに控える**。
  世界の側へ戻すのは 3 の仕事

## 2-4 推敲

checklist.md を上から順に当てる。
直しながら読むのではなく、**通読 → メモ → 直す**の順で。

# 3 世界観更新モード

**`novels/stories` の生成結果から、世界の側を更新する。**
本文を書くと必ず新しい設定が生まれる。街の名前、酒場の主人、力の副作用。
**後回しにすると必ず矛盾する。**

## 3-1 文章の側を先に直す

**文章が正で、台帳が従。** 順番を逆にしない。

- 新しく出した場所 → `novels/worlds/<世界線>/**/<場所>/<場所>.md`
- 新しく出した種別 → `novels/objects/<世界線>/<種別>.md`
- 新しく出した個体（群） → `novels/objects/<世界線>/**/<個体>/<個体>.md`。
  **本文に名前を出した時点で登録する**
- 新しく出した人物 → `novels/characters/<出身地>/**/<人名>/<人名>.md`。
  **台詞を一つでも喋らせたら登録する。** 一人称・二人称・三人称を必ず埋める
- 新しく出した語 → `novels/terms/<語>/<語>.md`（上位の語があればその中へ）

既存の設定と食い違う本文を書いてしまったら、本文のほうを直す。
既存の設定は基本的に変更しない。

## 3-2 起きたことを出来事として積む

一話書いたら、最低でもこれだけは足す。**上書きしない。新しい年を足す。**

| 何を                 | どこに                                                            |
| -------------------- | ----------------------------------------------------------------- |
| その話で起きたこと   | `<場所>/events/{時刻}_{名}.md`                                    |
| 動いた数             | 同上。種別 `指標`                                                 |
| 変わった間柄         | 同上。種別 `関係`                                                 |
| 主要人物がやったこと | `<人名>/actions/{時刻}_{名}.md`。**動機と代償と結果をそろえて**。`出来事` に、関わった出来事の名を必ず書く |
| 人が移った先         | `<人名>/places/{時刻}_{場所}.md`                                  |
| 群が動いたこと       | `<個体>/actions/{時刻}_{名}.md`・`<個体>/places/{時刻}_{場所}.md` |
| 人物が変わったこと   | `<人名>/<人名>.md`。**嘘を捨てたなら `嘘` と `必要` を直す**   |


## 3-3 締め

```
python3 tools/novel.py check                      # error 0 で終える
python3 tools/novel.py index --world <世界線>      # 語を足したなら
python3 tools/novel.py build                      # 断面を次に取るために組み直す
```

**error を残したまま次の話へ行かない。** 次の断面が嘘になる。

## どのモードにいるか分からなくなったら

| 頼まれたこと                                     | モード                              |
| ------------------------------------------------ | ----------------------------------- |
| 「新しい世界を作って」「この星に国を足して」     | 1                                   |
| 「3 話を書いて」「続きを書いて」                 | 2                                   |
| 「書いたぶんを設定に反映して」「台帳を更新して」 | 3                                   |
| 「設定の矛盾を直して」                           | 1（既存の世界を直すのも構成のうち） |

**頼まれていない話数を勝手に書き足さない。**
**指示がないかぎり、過去の原稿を「ついでに」推敲して書き換えない。**
