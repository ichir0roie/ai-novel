# 執筆ワークフロー

## 全体の流れ

```
企画 → 世界観 → プロット → 本文 → 推敲
 ↑                              │
 └──── 設定の書き戻し ←──────────┘
```

## 1. 企画（worlds/<宇宙>/stories/<作品名>/meta.md）

最初に決めるのは 3 つだけ。細かい設定は後でいい。

- **ログライン**: 「誰が、何を望み、何に阻まれる話か」を 1 文で
- **売り**: この作品の何が面白いのか。読者が友達に説明するときの一言
- **読後感**: 読み終わったときにどんな気持ちでいてほしいか

ここが曖昧なまま設定を膨らませると、面白くない設定資料ができあがる。

## 2. 世界観（worlds/<世界観名>/）

**物語に必要な分だけ作る。** 世界地図を全部埋める必要はない。

作るべきは「主人公の行動を制限するルール」と「対立の火種」。
制限のない世界では何も起きない。

- 既存の世界観を使い回すなら新規作成は不要。その宇宙の `stories/` に作品を足すだけ
- 1 つの世界観で複数作品を書けるのがこの構成の狙い
- **作品は必ずひとつの宇宙の中で完結する。** 本文は `worlds/<宇宙>/stories/` の下に置く。
  新しい宇宙を起こすときは `python3 tools/chronicle.py init --world <宇宙名>` で台帳ごと作る

## 3. プロット（worlds/<宇宙>/stories/<作品名>/plot.md）

- まず結末を決める。ゴールが決まっていないと道中が迷走する
- 次に中間点（主人公の目的や立場が反転する場面）を決める
- 最後に各話へ割る。1 話あたり「山場ひとつ、引きひとつ」

## 4. 本文（worlds/<宇宙>/stories/<作品名>/episodes/NNN.md）

**書きはじめる前に断面を取る。** 星・年・場所を決めて、その時点の世界を一枚に出す。

```
python3 tools/chronicle.py brief --world <宇宙> --star <星> --year <年> --place <場所>
```

いま何が張っているか（火種）、まだ終わっていない出来事は何か、誰が生きていて、
数がどちらへ動いているかが出る。**設定ファイルを頭から読み直すより早い。**
本文を書くあいだは `--full` を付けない。詳しくは `core/chronicle.md`。

1 話を書きはじめる前に、その話の中で**変化するもの**を 1 つ確認する。
関係・情報・状況のいずれかが動かない話は、削れる話。

書く順番は、場面の頭から順に。難しい場面を飛ばして後から埋めない
（前後のテンションが合わなくなる）。

## 5. 推敲

`core/checklist.md` を上から順に当てる。
直しながら読むのではなく、通読 → メモ → 直す、の順で。

## 6. 設定の書き戻し（重要）

本文を書くと必ず新しい設定が生まれる。街の名前、酒場の主人、魔法の副作用。
書き終わったらその場で `worlds/` 側に転記する。後回しにすると必ず矛盾する。

転記は二段ある。**文章側に書いてから、台帳側にも足す。**

```
python3 tools/chronicle.py add --world <宇宙> --table event --set 年=... --set 出来事=...
python3 tools/chronicle.py check --world <宇宙>
```

足すのは、起きたこと（`出来事.md`）、人物がやったこと（`行動.md`。**動機と代償と結果をそろえて**）、
動いた火種（`火種.md`）、出した人物（`人物.md`）、動いた数（`指標.md`）。
**どの火種の値も動かなかったなら、その話は弱い。** `core/chronicle.md`。
