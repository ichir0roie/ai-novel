# 執筆ワークフロー

作業は**三つのモード**に分かれている。**一度に一つだけやる。**
混ぜると、設定を作りながら本文を書き、本文を書きながら設定を直すことになって、
どちらも中途半端に終わる。

```
  ┌──────────────┐   ┌──────────────┐   ┌──────────────┐
  │ 1 世界観構成  │ → │ 2 ストーリー  │ → │ 3 世界観更新  │
  │   モード      │   │   生成モード  │   │   モード      │
  └──────────────┘   └──────────────┘   └──────────────┘
         ↑                                      │
         └──────────────────────────────────────┘
   worlds / objects         stories            起きたことを
   / characters / terms      を書く             世界の側へ戻す
   を作る
```

1 は最初の一度だけ。**あとは 2 と 3 をひたすら回す。**

|                      | 読むもの                             | 書くもの                                       |
| -------------------- | ------------------------------------ | ---------------------------------------------- |
| **1 世界観構成**     | `core/` と、あれば既存の世界         | `novels/worlds` `objects` `characters` `terms` |
| **2 ストーリー生成** | **直前の 10 話**と断面（`brief`）    | `novels/stories`                               |
| **3 世界観更新**     | 書いた本文                   | `novels/worlds` `objects` `characters` `terms` |

**2 のあいだは世界の側を触らない。3 のあいだは本文を触らない。**
本文を書いている途中で設定を作りたくなったら、メモに書き出して 3 まで持ち越す。

置き場所の決まりは chronicle.md。形は `tools/schema.py` が決めている。

## どのモードでも共通：md は python 越しにしか触らない

`novels/` のマークダウンを直に開かない。**作業の始めに読み込み、終わりに書き出す。**

```
python3 tools/novel.py load     はじめに一度。md を novels/novel.db へ入れる
python3 tools/novel.py save     おわりに一度。db を md へ書き出す
```

作業中は db 相手に読み書きする。設定は `brief` `list` `show` `sql` で読み、
本文は `stories` `read` `write` で読み書きする（一覧は CLAUDE.md）。
入口が足りなければ `tools/` に関数を足す。md を直に開いて済ませない。

# 1 世界観構成モード

**`novels/worlds` `objects` `characters` `terms` を作るところまで。**
このモードでは `novels/stories` を一行も書かない。

## 1-1 企画を先に決める

細かい設定より先に、これだけ決める。設定から始めると、
**面白くない設定資料ができあがる。**

- **ログライン**: 「誰が、何を望み、何に阻まれる話か」を 1 文で
- **売り**: 読者が友達に説明するときの一言
- **読後感**: 読み終わったときにどんな気持ちでいてほしいか

**どれも AI が先に決めない。** まず作者に聞く。作者が「アイデアがない」と
言ったときだけ、AI が案を出す（principles.md「発想の主権」）。

## 1-2 世界を起こす

**物語に必要な分だけ作る。** 世界地図を全部埋める必要はない。
作るべきは「**主人公の行動を制限するルール**」と「**対立の種**」。
制限のない世界では何も起きない。イベントを起こすのは作者の意思であって、
値の推移が自動で話を要求する仕組みではない。

作る順番はこれで固定する。**前を飛ばして後ろを作らない。**

| 順  | 何を                                 | どこに                                              |
| --- | ------------------------------------ | --------------------------------------------------- |
| 1   | **世界線**（いちばん外の場所）       | `novels/worlds/<世界線>/<世界線>.md`                |
| 2   | **星・大陸・地形**（場所の木）       | `novels/worlds/<世界線>/**/<場所>/<場所>.md`        |
| 3   | **種別**（系統・国・組織・仕組み）   | `novels/objects/<世界線>/<種別>.md`                 |
| 4   | **個体**（その種別の、名前のある群） | `novels/objects/<世界線>/**/<個体>/<個体>.md`       |
| 5   | **人物**（一人ひとりの人間）         | `novels/characters/<出身地>/**/<人名>/<人名>.md` |
| 6   | **出来事**（年表・指標・関係）       | `<場所>/events/{時刻}_{名}.md`                      |
| 7   | **語**                               | `novels/terms/**/<語>/<語>.md`                      |

**`terms/` は世界線でディレクトリを切らない。** どの世界線の語かは上段の
`世界` が持つ。**`characters/` は世界線ではなく出身地で切る**（chronicle.md）。

**5 は作品が決まってから。** 世界だけ作るあいだ、人物は要らない。
群としての振る舞い（4）と、一人ひとりの中身（5）を混ぜない（chronicle.md）。

雛形は `python3 tools/novel.py template --kind 場所` で出る。

**既存の世界を使い回すなら、このモードは要らない。** 2 から始める。
一つの世界で何本も書けるのがこの構成の狙いである。

## 1-3 アバウトなところの決め方

人口・年代・比率のように、設定から読めない数や要素も、順番は 1-1 と同じ。

1. まず作者に聞く
2. 既存の `novels/terms/` `novels/objects/` に当てはまるものがあれば提示する
3. 作者にアイデアがないときだけ `tools/roll.py` で振る。
   **AI の第一想起で埋めない**（principles.md）。
   引いた目とシードは `novels/worlds/<世界線>/rolls.md` に残す


## 1-4 締め

```
python3 tools/novel.py check                      # error 0 で終える
python3 tools/novel.py index --world <世界線>      # 用語索引を作り直す
```

# 2 ストーリー生成モード

**`novels/worlds` `objects` `characters` `terms` を元に、`novels/stories` を書く。**
このモードでは世界の側を一行も書き換えない。

順番は **同期の確認（2-0）→ 直前の 10 話（2-1）→ プロット（2-2）→
顔ぶれと断面（2-3）→ 本文（2-4）→ 推敲（2-5）**。
**展開を考えるのは、前の話を読んだあと。**

## 2-0 未同期の話が残っていないか見る

話には `同期` フラグがある。**その話で起きたことが台帳へ戻っているか**を持つ欄で、
モード 3 を通すまでは下りている。下りている話があるあいだ、
`episodes` `brief` `cast` は材料を出さずに止まる。古い台帳の上で
次の話を組み立てると、断面も顔ぶれも一話ぶん古いままになるからである。

```
python3 tools/novel.py sync                          未同期の話を並べる
python3 tools/novel.py sync <作品名>/<話数>           モード 3 のあと、立てる
python3 tools/novel.py sync <作品名>/<話数> --off     下ろす
```

**止まったら、モード 2 をいったん置いてモード 3 をやる。**
`--skip-sync` は、読むだけで何も書かないときの逃げ道であって、
これを付けて次の話を書かない。

## 2-1 直前の 10 話を読む

**展開を考える前に、直前の 10 話を読む。** ここを飛ばさない。
前の話で誰が何を言ったか、どこで終わったかを覚えていないまま次を考えると、
同じ場面をもう一度書く・前話の引きを拾い落とす・口調が変わる。

```
python3 tools/novel.py episodes --story <作品名>              # 最新 10 話
python3 tools/novel.py episodes --story <作品名> --before 15  # 15 話の前 10 話
python3 tools/novel.py episodes --story <作品名> --list       # 話数と題だけ
```

読むのは原稿そのもの（`novels/stories/<作品名>/episodes/` の中身が
そのまま出る）。10 話に満たなければ、あるだけ出る。
**読んでから 2-2 のプロットに進む。**

## 2-2 プロット

**結末を先に決めない。** 次に何が起きるかは、そのつど候補を出して相談する。

- 候補は次から拾う: **直前の 10 話でまだ回収していない引き**（2-1）、
  登場人物の `欲` `恐れ` `嘘` `必要`（characters.md）、
  個体の `actions/` に書かれていない次の一手、まだ終わっていない出来事、
  その場所にいる別の人物・個体
- 候補が浮かばないときは `tools/roll.py` などで複数出し、作者に提示する。
  **作者が選ぶ。AI が決めない**（principles.md「発想の主権」）
- 決まった分だけ `plot.md` に積む。**先の話数まで無理に埋めない**
- 山場・引きは 1 話ずつ、書く直前に決めてよい

置き場所は `novels/stories/<作品名>/plot.md`。企画は `meta.md`。
`meta.md` には、**どの世界線のどの場所・どの年に立つか**を書く。

## 2-3 顔ぶれと断面を取る

**設定ファイルを頭から読み直さない。** 材料は二枚で足りる。

### 顔ぶれ（誰がいて、その人に何が起きたか）

```
python3 tools/novel.py cast --story めぐる旅路は枯れゆく世界と
```

作品が立つ場所の**一つ上**を基準に、その配下の場所にその時点で居る
人物と個体を集め、一人（一群）ずつ**直近 5 件の出来事**を並べる。
`--time` を付けなければ作品の始まりの年、`--count` で件数を変えられる。

一つ上を基準にするのは、その話に出せる者が村の中だけとは限らないからである。
隣の集落にいる者も、島を回っている群も、同じ枠に入ってくる。
**その話に誰を出せるかは、ここで決める。** 思いついた名前を先に置かない。

### 断面（世界がどうなっているか）

```
python3 tools/novel.py brief --place ムシュヴァン --time 4360
```

いま数がどちらへ動いているか、まだ終わっていない出来事は何か、
誰がその場にいて、何が張っているかが出る。
**3 節の「直近の出来事」は既定で 60 年ぶん。** もっと遡りたいときは
`--reach 200` のように伸ばす。

> **`--full` を付けない。** 付けると住人が知らないことまで出て、
> それを本文に書いてしまう。裏を設計するときだけ付ける。

断面の「その場にいる者」には、個体（群）と人物が並んで出る。
**その話で喋る人物は、断面のあとに一件ずつ読んでおく。**

```
python3 tools/novel.py show <人名>
```

一人称・二人称・三人称・口調がここにある。**本文の呼び方はこれに従う。**
書きながら決め直さない。決め直したくなったら、それはモード 3 の仕事である。

## 2-4 本文

`novels/stories/<作品名>/episodes/<話数>.md`。**1 話 1 ファイル**、
ファイル名は話数だけ（`3.md`）。**ゼロ埋めしない。**

書きはじめる前に、その話の中で**変化するもの**を 1 つ確認する。
関係・情報・状況のいずれかが動かない話は、**削れる話**である。

- 書く順番は場面の頭から順に。難しい場面を飛ばして後から埋めない
  （前後のテンションが合わなくなる）
- **要約で済ませない。** 「〜という展開があった」で流さず、場面として書く
- **数を本文に出さない。** 台帳の数は作者だけが見る（chronicle.md）
- 途中で新しい設定が生まれたら、**本文にだけ書いて、メモに控える**。
  世界の側へ戻すのは 3 の仕事

## 2-5 推敲

checklist.md を上から順に当てる。
直しながら読むのではなく、**通読 → メモ → 直す**の順で。

# 3 世界観更新モード

**`novels/stories` の生成結果から、世界の側を更新する。**
本文を書くと必ず新しい設定が生まれる。街の名前、酒場の主人、力の副作用。
**後回しにすると必ず矛盾する。**

## 3-1 文章の側を先に直す

**文章が正で、台帳が従。** 順番を逆にしない。

- 新しく出した場所 → `novels/worlds/<世界線>/**/<場所>/<場所>.md`
- 新しく出した種別 → `novels/objects/<世界線>/<種別>.md`
- 新しく出した個体（群） → `novels/objects/<世界線>/**/<個体>/<個体>.md`。
  **本文に名前を出した時点で登録する**
- 新しく出した人物 → `novels/characters/<出身地>/**/<人名>/<人名>.md`。
  **台詞を一つでも喋らせたら登録する。** 一人称・二人称・三人称を必ず埋める
- 新しく出した語 → `novels/terms/<語>/<語>.md`（上位の語があればその中へ）

既存の設定と食い違う本文を書いてしまったら、本文のほうを直す。
既存の設定は基本的に変更しない。

## 3-2 起きたことを出来事として積む

一話書いたら、最低でもこれだけは足す。**上書きしない。新しい年を足す。**

| 何を                 | どこに                                                            |
| -------------------- | ----------------------------------------------------------------- |
| その話で起きたこと   | `<場所>/events/{時刻}_{名}.md`                                    |
| 動いた数             | 同上。種別 `指標`                                                 |
| 変わった間柄         | 同上。種別 `関係`                                                 |
| 主要人物がやったこと | `<人名>/actions/{時刻}_{名}.md`。**動機と代償と結果をそろえて**。`出来事` に、関わった出来事の名を必ず書く |
| 人が移った先         | `<人名>/places/{時刻}_{場所}.md`                                  |
| 群が動いたこと       | `<個体>/actions/{時刻}_{名}.md`・`<個体>/places/{時刻}_{場所}.md` |
| 人物が変わったこと   | `<人名>/<人名>.md`。**嘘を捨てたなら `嘘` と `必要` を直す**   |


## 3-3 締め

```
python3 tools/novel.py sync <作品名>/<話数>        # 同期フラグを立てる
python3 tools/novel.py check                      # error 0 で終える
python3 tools/novel.py index --world <世界線>      # 語を足したなら
python3 tools/novel.py build                      # 断面を次に取るために組み直す
```

**error を残したまま次の話へ行かない。** 次の断面が嘘になる。
**同期フラグを立てないまま次の話へも行かない。** 2-0 で止まる。

## どのモードにいるか分からなくなったら

| 頼まれたこと                                     | モード                              |
| ------------------------------------------------ | ----------------------------------- |
| 「新しい世界を作って」「この星に国を足して」     | 1                                   |
| 「3 話を書いて」「続きを書いて」                 | 2                                   |
| 「書いたぶんを設定に反映して」「台帳を更新して」 | 3                                   |
| 「設定の矛盾を直して」                           | 1（既存の世界を直すのも構成のうち） |

**頼まれていない話数を勝手に書き足さない。**
**指示がないかぎり、過去の原稿を「ついでに」推敲して書き換えない。**
