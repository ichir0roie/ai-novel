# 推敲チェックリスト

書き上げた直後ではなく、一度置いてから当てる。

## 構成

- [ ] この話で変化したもの（関係・情報・状況）を 1 つ言えるか
- [ ] 冒頭 3 行で場所・時間・誰がいるかがわかるか
- [ ] 引きは効いているか。書きすぎて余韻を潰していないか
- [ ] 前話の終わりとこの話の頭が繋がっているか

## 文章

- [ ] 5 行以上続く地の文はないか
- [ ] 同じ段落で同じ動詞・同じ語尾が 3 回以上出ていないか
- [ ] 「〜のだった」「〜のである」が多すぎないか
- [ ] 一文が長すぎる箇所を割れないか
- [ ] 説明の塊を、必要な行の直前に分散できないか

## キャラ

- [ ] 台詞だけ抜いて誰の発言かわかるか
- [ ] 登場したのに何もしていない人物がいないか
- [ ] 主人公が状況に流されるだけになっていないか（選択をさせる）

## 設定

- [ ] 世界の側（`worlds/` `objects/` `characters/` `terms/`）と矛盾していないか
      （固有名詞の表記ゆれ含む）
- [ ] 人物の呼び方が `character.md` の `一人称` `二人称` `三人称` どおりか
- [ ] 本文で新しく生まれた設定を、モード 3 で世界の側へ書き戻したか
- [ ] `python3 tools/novel.py check` が error 0 で通るか
- [ ] 主人公が知らないはずの情報を知っていないか（一人称は特に注意）

## 最後に

- [ ] 声に出して読んで、つっかえる箇所を直したか
- [ ] 自分がこの話の続きを読みたいか
