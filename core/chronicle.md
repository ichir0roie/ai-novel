# 世界の記録と、話が尽きない仕組み

`core/workflow.md` が「**どの順で進めるか**」なら、ここは「**どう貯めるか**」。

## 何のためにあるか

話が続かなくなる理由は、たいてい二つしかない。

1. **前に何を決めたか忘れる。** 設定ファイルを全部読み直さないと書けなくなる
2. **次に何が起きるか思いつかなくなる。** 世界が静止していて、
   書き手が毎回ゼロから事件を発明している

どちらも、**世界の状態を時間つきで持っていない**ことから来る。
だから、設定を文章で持つのとは別に、**記録**として持つ。

## 一レコード一ファイル

**front matter がレコード、その下が文章。** 同じファイルにあるので二重管理にならない。

```markdown
---
名: 信仰
種別: 制度
世界: SFファンタジー
星: 入植星
出典: novels/worlds/SFファンタジー/入植星/解釈表.md
---

# 信仰

**この星では、信仰が篤いほど魔力が強い。迷信ではない。**
（ここから下は人間が読む文章。長さに制限はない）
```

**同じことを二度書かない。** front matter に書いたことを本文で繰り返さない。

## 置き場所がレコードの種類を決める

**どこに置くかで、何のレコードかが決まる。** front matter には中身だけを書く。

```
novels/
  worlds/<世界線>/<世界線>.md                       場所（いちばん外）
  worlds/<世界線>/**/<場所>/<場所>.md               場所
  worlds/<世界線>/**/<場所>/events/{時刻}_{名}.md   出来事
  objects/<世界線>/<種別>.md                        種別
  objects/<世界線>/**/<個体>/object.md              個体
  objects/<世界線>/**/<個体>/places/{時刻}_{場所}.md  居場所
  objects/<世界線>/**/<個体>/actions/{時刻}_{名}.md   行動
  characters/<出身地>/**/<人名>/character.md        人物
  characters/<出身地>/**/<人名>/places/{時刻}_{場所}.md  人物居場所
  characters/<出身地>/**/<人名>/actions/{時刻}_{名}.md   人物行動
  terms/**/<語>/term.md                             語（入れ子にできる）
  stories/<作品名>/…                                本文。記録には入らない
```

決まりは四つ。

- **ディレクトリ名と同じ名前の md だけが、その場所のレコード。**
  だから `history.md` や `解釈表.md` を隣に置いてよい。それは自由文書として読み飛ばされる
- **`{時刻}` は `{年}_{mm}_{dd}`。** 時刻まで要るときだけ後ろに `{hhmmss}` を足す
  （`4340_01_01_耐用年数の満了.md` / `4340_01_01_093000_耐用年数の満了.md`）。
  **月日は二桁で揃える。年は西暦で、上限はない**（`99999_01_01_…` も置ける）
- **front matter の中は `y/mm/dd hh:mm:ss` で書く。**
  後ろから欠けた分は書かなくてよい（`4360/7/12` / `4360`）。
  **ファイル名も front matter も、この二つの書き方だけ**（`tools/stamp.py`）
- **id は書かない。** 読み込むときに、上位のレコードの id と自分の名から採番する
  （`入植星/森`、`SFファンタジー/入植星/森/4340_01_01_耐用年数の満了`）。
  **他を指す欄（`親` `場所` `出来事` `分類` `種族` `所属`）には名前を書く。**
  同じ名が二つあると寄せ先が決まらないので、そのときは名のほうを分ける
- **入れ子が所属を表す。** `ムシュヴァン/商人組合/` と置けば、
  商人組合がムシュヴァンの内側にいることが構造で分かる

### 種別・個体・人物

| | 何を入れるか | 例 |
| --- | --- | --- |
| **種別**（`objects/<世界線>/<種別>.md`） | **型。** 何であるかの分類 | 系統、国、組織、仕組み、魔族 |
| **個体**（`objects/**/<個体>/object.md`） | **その型の、名前のある群** | ムシュヴァン、神殿、森、さいはい |
| **人物**（`characters/<出身地>/<人名>/character.md`） | **一人ひとりの人間** | （作品ごとに作る） |

**種別 1 に対して個体が何個でもぶら下がる。**
個体と人物だけが、居場所と行動の時系列を持つ。行動の主語になれるのはこの二つである。

#### 個体と人物の線引き

**「みんな」と言えるなら個体、「この人」としか言えないなら人物。**

- **個体は群の振る舞いを持つ。** 魔族が追われる、商人組合が名簿を握る、
  神殿が登録を絞る。誰か一人の意思ではなく、**まとまりとしての動き**
- **人物は一人ひとりの中身を持つ。** 何を欲しがり、何を信じ違え、何を恐れるか。
  背丈も、一人称も、口調も、人物にしかない

**人物は種族として個体を指す。** `種族` に種別、`所属` に個体を書けば、
「商人組合に属する魔族の娘」が一行で立つ。
**群の設定を人物の側へ写さない。** 魔族の性質は種別に一度だけ書く。

#### 人物がいちばん細かい理由

本文は一人称・二人称・三人称で人を指す。**その三つが決まっていないと書けない。**

| 欄 | 何のためにあるか |
| --- | --- |
| `一人称` `二人称` | 台詞が誰のものか、読者が名札なしで分かるため（`core/characters.md`） |
| `三人称` | **地の文がこの人物をどう呼ぶか。** 途中で変えない |
| `口調` | 語彙・文の長さ・語尾。**語尾芸に頼らない** |
| `性格` `感情` `思想` | 同じ状況で何に注目し、何に揺れ、何を正しいと思うか |
| `欲` `嘘` `必要` | 造形の芯。**設定表に体重を書くより、この 3 行が効く** |
| `恐れ` | 引き返す線。ここを踏ませると場面になる |
| `能力` `代償` | **代償の無い能力は書かない。** 制限のない設定は物語を殺す |
| `性別` `背丈` `体格` `見た目` | 絵にするとき迷わない分だけ |

**空欄でよい。** 決まっていないことを埋めるために作らない。
決めたなら、**本文より先にここへ書く**（`core/workflow.md`）。

### 語と個体は役割が違う

「さいはい」という**組織**は個体、「さいはい」という**語**（正式名称は再配分機構）は語。
**名前は語の側、振る舞いは個体の側。** 両方あってよい。

## 出来事は一種類しかない

**起きたこと・数・間柄・張っているもの。全部「出来事」として積む。**
違いは `種別` だけ。

| 種別 | 何を入れるか | 書き方 |
| --- | --- | --- |
| （自由） | 起きたこと。`災害` `制度` `技術` `争点` など | 終わっていないなら `終` を空にする |
| `指標` | 数で追えるもの。人口・資源・値段 | 名を「人口 27400000 人」の形にする |
| `関係` | 誰と誰が、どういう間柄か | 本文に強度 -3〜3 を書き、両者から `actions/` で吊る |
| `火種` | 張っているもの | 本文に**対立軸**と**限界で起きること**を書く |
| `火種/値` | 火種の値が動いたこと | `親` に火種の**名**。**上書きせず、新しい年を足す** |

### `/` で付ける注記

`種別` の後ろに `/` で注記を足せる。**断面の出しかたが変わる。**

| 注記 | 意味 | 断面での扱い |
| --- | --- | --- |
| `/裏` | 住人が知らない。**作者だけ** | 既定では伏せる。`--full` で出る |
| `/死語` | 使われなくなった語 | 既定では出さない |
| `/候補` | まだどの作品も採っていない呼び名 | 既定では出さない |
| `/設定側` | 本文に出さない語 | 既定では出さない |

`/裏` は、`novels/worlds/SFファンタジー/入植星/解釈表.md`
「表の物語の本文には、裏の語を一つも出さない」を、**記録の側から守るため**にある。

## 無限に続けるための考え方

### 世界は割り算でできている

`SFファンタジー` の骨格は一本の式である——**暮らし向き ＝ 取れる分 ÷ 人の数**。

この式に触るものは、全部物語になる。分子が減れば事件になり、分母が減れば儀式になり、
**誰が分ける権利を持つか**でそのまま政治になる。地球ではそれが政策になり、
入植星では生贄になった。**同じ割り算が、星ごとに違う顔をしているだけ**である。

だから `指標` の出来事は飾りではない。**分子と分母を置く場所**であり、
そこが動いた瞬間、書くべき場面が生まれる。

### 話は火種から生える

事件を発明しない。**張っているものを探して、それを切る。**

火種には、対立軸と「値が限界まで行くと何が起きるか」が書いてある。
一本書くというのは、**どれかの火種の値を動かすこと**である。

- 値が上がったなら、次の話が近づいた
- 値が下がったなら、誰かが何かを差し出して抑えた。**その代償を行動に書く**
- 一本書いても何の値も動かないなら、その話は削れる

**火種は減らない。** 一つ切れば、切った側に新しい火種が立つ。
配る権利を奪った者は、次の話では配る側として憎まれる。そこが尽きない理由である。

### 過去は消さない。積む

**追記式。** 行を書き換えず、新しい年のファイルを足す。
ある火種が 3540 年に 3、4340 年に 4 なら、**八百年かけて張ってきた**ことが残る。
推移そのものが、次に書くときの手がかりになる。

## 書く前——断面を取る

その話が立つ**場所と年**を決めて、断面を出す。設定ファイルを読み直すより先にこれ。

```
python3 tools/novel.py brief --place 霧湊大陸 --time 4360
```

出るもの。

| 節 | 何が読めるか |
| --- | --- |
| 1 いまの数値 | 分子と分母。その時点で最後に記録された値 |
| 2 続いている出来事 | まだ終わっていないもの。**背景に置くべきもの** |
| 3 直近の出来事 | 登場人物が覚えている範囲の過去 |
| 4 その場にいる者 | 生没つき。死んだ者と生まれる前の者は出ない |
| 5 この射程での行動 | 誰が何をして、**何を失ったか** |
| 6 張っている火種 | **次の一手の候補。**最後に動いた値つき |
| 7 ここで使える語 | その場所に届いている語だけ |
| 8 ここからは見えないこと | 件数だけ。`--full` で中身が出る |

`--place` は、**その場所・その内側・その外側**に効く。
外側から来たものには「（広域）」が付く。それが**周辺環境**である。

八節に件数が出るのは意図的で、「**この時点には、まだ書けないことが 4 件ある**」と
分かっているほうが、住人の無知を正しく書ける。

- **本文を書くとき**: `--full` を付けない。伏せられたまま書く
- **裏を設計するとき・繋ぎを確認するとき**: `--full` を付ける

## 書いたあと——記録に戻す

`core/workflow.md`「3 世界観更新モード」を見る。**文章に書き戻したら、記録にも足す。**

```
novels/worlds/SFファンタジー/霧湊大陸/events/4361_03_01_登録の値が二倍になる.md
```

```markdown
---
種別: 経済
出典: novels/stories/<作品名>/episodes/001.md
---

# 登録の値が二倍になる

（何が起きたか。**出典を必ず書く。出典のない記録を足さない**）
```

最後に検める。**error が残ったまま次の話へ行かない。**

```
python3 tools/novel.py check
```

## 数を本文に出さない

`core/principles.md` は**ステータス画面・レベル・数値で強さを説明することを禁じている。**
この記録はそれに反しない。**反しないように使う。**

- 記録の数は、`core/naming.md` でいう**設定側の名**と同じ扱い。**作者だけが見る**
- 「器 4」と本文に書かない。**書くのは、四人ぶんの井戸を一人で汲み上げてしまう場面**
- 火種の値は、緊張の量を作者が測るための目盛りであって、作中の誰も知らない
- 数が動いたことは、**必ず場面として書く**

**数は、何を書くかを決めるためにある。何を書いたかを説明するためではない。**

## 形は一か所で決まっている

**`tools/schema.py`（SQLAlchemy のモデル）が、DB の列も front matter の欄も決めている。**
欄を増やしたければ `schema.py` を直す。**マークダウン側に勝手な欄を足さない。**
スキーマに無い欄を書いたファイルは、**黙って捨てられずに `check` で止まる。**

| 欄 | どのレコードにあるか |
| --- | --- |
| `名` | 場所・出来事・種別・個体・人物・語 |
| `種別` | 場所・出来事・種別・個体・語 |
| `読み` | 種別・個体・人物 |
| `親` | 場所（上位の場所）・出来事（上位の出来事） |
| `始` `終` | 場所・出来事・種別・個体・居場所・行動 |
| `生` `没` | 人物（`始` `終` ではなくこちら） |
| `時` | 出来事（省略時はファイル名の時刻） |
| `場所` | 出来事・居場所・語 |
| `分類` | 個体（どの種別か） |
| `世界` `星` | 種別・個体・語 |
| `出身` | 人物（省略時はディレクトリ名。どの場所で生まれたか） |
| `種族` `所属` | 人物（種族は種別、所属は個体を指す） |
| `性別` `背丈` `体格` `見た目` | 人物 |
| `一人称` `二人称` `三人称` `口調` | 人物 |
| `性格` `感情` `思想` `欲` `嘘` `必要` `恐れ` | 人物 |
| `能力` `代償` | 人物。**代償を空にしない** |
| `出来事` | 行動（どの出来事に関わったか） |
| `出典` | **全部。空にしない** |

雛形はツールが出す。

```
python3 tools/novel.py template --kind 場所      # 場所/出来事/種別/個体/居場所/行動/人物/人物居場所/人物行動/語
```

## ツール

```
pip install -r requirements.txt     # SQLAlchemy と PyYAML が要る
```

| ファイル | 役割 |
| --- | --- |
| `tools/schema.py` | **形。** DB の列と front matter の欄を決める |
| `tools/reader.py` | **読み取り。** マークダウンをレコードに起こす |
| `tools/novel.py` | 入口。下のコマンドを持つ |
| `tools/roll.py` | 乱数。設定をアバウトに決めるとき |

| | |
| --- | --- |
| `check` | 不備を探す。**error があれば終了コード 1** |
| `build` | 記録から `novels/novel.db` を組み上げる |
| `brief --place <場所> --time <年>` | 断面を出す |
| `list --kind 語 --world <世界線>` | 一覧 |
| `show <名>` | 一件読む |
| `template --kind 人物` | 雛形を出す |
| `index --world <世界線>` | 用語索引を `glossary.md` に書き出す |
| `sql "SELECT …"` | 直接問い合わせる |

`sql` は、断面では出ない問いに使う。

```
python3 tools/novel.py sql \
  "SELECT name, time FROM event WHERE kind LIKE '火種%' ORDER BY time"
```

`novels/novel.db` は git に入れない。**記録から何度でも組み直せる**ので、
差分が読めないバイナリを履歴に残す意味がない。
