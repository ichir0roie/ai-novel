# 魔力

## 名と、表と裏

| | |
| --- | --- |
| 読み | まりょく |
| 表（住人の理解） | 体の中にある力 |
| 裏（設定側） | その人に配られている電力の残量 |
| 実体 | 采配 |


- **魔力切れ** — 使いすぎると倒れる。裏では割り当ての使い切り。采配が止めた
- **魔力の多寡** — 生まれつきの才。裏では系統と血統で等級が違う

総量は森が取った分しかない。**誰かが多く引けば、同じ区画の誰かの取り分が減る。**
