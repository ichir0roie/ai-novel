# 信仰

## 名と、表と裏

| | |
| --- | --- |
| 読み | しんこう |
| 表（住人の理解） | 篤いほど魔力が強くなるもの |
| 裏（設定側） | 森光の摩耗した形。**神殿に名を登録した者が、割り当てを受け取れる者である** |
| 実体 | 神殿 |


**この星では、信仰が篤いほど魔力が強い。迷信ではない。**

神殿に名を登録した者が、配られる者だからである。
「信仰が魔力を決める」は、表の説明としても裏の事実としても正しい。
