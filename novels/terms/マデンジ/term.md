# マデンジ

## 名と、表と裏

| | |
| --- | --- |
| 正式名称 | 坑守 |
| 通称 | マデンジ |
| 表（住人の理解） | 別の種族の一つ |
| 裏（設定側） | 地下の設備を保つために設計された系統 |

頑丈で背が低い。石と金物に強い。

住人は五つの系統を、互いに**別の種族**だと思っている。
本文で使うのは通称のほうで、**正式名称は住人の口に上らない。**
