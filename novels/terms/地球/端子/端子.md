# 端子

## 名と、表と裏

| | |
| --- | --- |
| 読み | たんし |
| 一言 | 体に埋めた接続口。首、腕、目のうしろ |


体に埋めた接続口。首、腕、目のうしろ。

後発の**無線**（端子を通さず直に繋ぐ）のほうが主流になったが、語としては残っている。

八百年かけて、**繋いだまま考える能力そのものが伸びた。**
生まれたときから繋がっている世代は、繋がっていない状態を「目をつぶっている」と言う。

ノウルの「**器**」は、これを体に生やしたもの。**あちらに機械の端子は一つもない。**
