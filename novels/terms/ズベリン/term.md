# ズベリン

## 名と、表と裏

| | |
| --- | --- |
| 正式名称 | 夜獸 |
| 通称 | ズベリン |
| 表（住人の理解） | 別の種族の一つ |
| 裏（設定側） | 森の夜と薄い空気への適応ために設計された系統 |

毛が濃い。夜目が利き、耳がいい。

住人は五つの系統を、互いに**別の種族**だと思っている。
本文で使うのは通称のほうで、**正式名称は住人の口に上らない。**

系統としての振る舞いは `novels/objects/SFファンタジー/ズベリン.md`。
