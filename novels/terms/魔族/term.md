# 魔族

## 名と、表と裏

| | |
| --- | --- |
| 読み | まぞく |
| 表（住人が使う） | 人の形をしているが、人ではないもの |
| 裏（設定側） | **系統外**。系統をまたいで生まれた人間 |

そばにいると村の力が痩せる、と言われる。**説明は間違っているが、観察は正しい。**

**住人が使うのはこの語だけ。** 裏の語は `系統外` にあり、本文には一度も出さない。
