# 積み過ぎ

## 名と、表と裏

| | |
| --- | --- |
| 読み | つみすぎ |
| 正式名称 | 違法接続体 |
| 通称 | 積み過ぎ |


線を越えて体に接続を積んだ者。**違法である。**

競技（楽器も運動も）と、戦争・治安の用途には接続を使えない。
使えば人ではなく武器になるから。

- 数は少ない。積むこと自体が高くつき、割り当てを大きく食う
- **強いが、隠れて生きるしかない。** 競技場にも、役所にも入れない
- さいはいの帳簿には載っている。**載っているから追える**

食う物も住む所も配られる社会で、**取り締まるべきものが、それしか残っていない。**
