# 森光

## 名と、表と裏

| | |
| --- | --- |
| 読み | しんこう |
| 表（住人の理解） | 森から来る光。着陸世代の技術用語 |
| 裏（設定側） | 着陸した世代の技術用語。**森から来る光**、それだけの意味 |


着陸世代が、森から来る力をそう呼んだ。ただそれだけの意味の技術用語だった。

| 時期 | 形 | 何が起きたか |
| --- | --- | --- |
| 3540 年代 | **森光**（しんこう） | 技術用語。書けるし読める |
| 3700 年代 | **しんこう** | 字が書けなくなり、音だけが残った |
| 3800 年代 | **信仰** | 音に別の字が当てられた |

**誰もこの二文字を読めない。**
