# 森

## ひとこと

| | |
| --- | --- |
| 一言 | 地表を覆う生物型ひなた。住人はこれを森と呼び、電気だと知らない |


## 表——住人の理解

**森。** はじめからあったもの。

人は森のそばにしか住めない。森から離れると何もできなくなる。
それだけを知っていて、理由は知らない。
**「森のない星に森を持ち込んだ者がいる」という発想が、この星には存在しない。**

## 裏

生物型ひなた。橙色矮星の弱い光を補うために、面積で稼ぐしかなかった。
放っておかれた八百年で、平地をほぼ覆い尽くした。

森がしている四つの仕事——**熱・水・空気・土の組成**——を、
住人は火・水・風・土の四属性と呼んでいる。**借りているだけである。**

## 何をするか

- 光を取り、電気に変え、采配へ渡す
- **自分の修理と運搬のために手足を作る。** 住人はそれを魔物と呼ぶ。
  古い個体ほど権限が高いので、言葉が通じることがある（竜）
- 局所的な自律単位を持つ。話しかけると応える。住人はそれを精霊と呼ぶ

## 制限

- **森のないところには何も届かない。** 高地は土が痩せていて森にならない
- 光で自分を直す。**光が来ないところでは、森も治らない**
- 4340 年、耐用年数が満了した。**年数が切れた仕組みは、命令を拒まない**
