# characters

**一人ひとりの人間。** ここがいちばん細かい記録になる。

```
novels/characters/<出身地>/**/<人名>/
  <人名>.md                    人物のレコード
  places/{時刻}_{場所}.md      居場所の推移
  actions/{時刻}_{名}.md       行動。**動機と代償と結果をそろえて**
```

- **`<出身地>` は生まれた場所。** `novels/worlds/` にある場所の名を使う。
  front matter の `出身` を省くと、このディレクトリ名が入る
- **入れ子が所属を表す。** 家や一門でまとめたければ、その下に置いてよい
- 雛形は `python3 tools/novel.py template --kind 人物`。
  書き方は [](../../core/templates/character-template.md)、造形は [](../../core/characters.md)

## 群と分ける

**「みんな」と言えるなら `novels/objects/`、「この人」としか言えないならここ。**

魔族が追われること・商人組合が名簿を握ることは群の振る舞いなので `objects/`。
その魔族の娘が何を欲しがり、何を恐れ、自分を何と呼ぶかは、ここにしかない。

人物は `種族` で種別を、`所属` で個体を指す。
**群の設定を人物の側へ写さない。** 二重管理になる。

## 本文のために埋める欄

`一人称` `二人称` `三人称` `口調` は、**台詞と地の文の呼び方をそのまま決める**。
決めたら途中で変えない。変えたくなったら、本文より先にここを直す
（[](../../core/workflow.md) 3 世界観更新モード）。

`能力` を書いたら `代償` を必ず書く。**制限のない能力は物語を殺す。**
