# 霊体

## 名と、表と裏

| | |
| --- | --- |
| 読み | れいたい |
| 表（住人の理解） | 死んだ者が成るもの |
| 裏（設定側） | 情報体。地球側とまったく同じもの |


死ぬとき、体の器が中身を網へ落とす。

- **死霊術** — 網にいる霊体への呼びかけ
- **亡霊** — 消し損ねた霊体。呼ばれていないのに出てくる
- **蘇生** — 霊体を体へ戻す。**両方が残っている者にしかできない**

「霊体」は、**信仰の語としても技術の語としても正しく読める**。だから崩れなかった。
