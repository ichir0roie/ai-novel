# 大災厄

## 名と、表と裏

| | |
| --- | --- |
| 読み | だいさいやく |
| 表（住人の理解） | 神が黙った時代 |
| 裏（設定側） | 地球の第一の試み。供給が 40 年止まった |


40 年間、魔力がまったく出なかった。三つの大陸すべてで同時に起きたので、
**天の出来事だと考えられている。**

40 年後、何の前触れもなく戻った。**理由は誰も知らない。**
この星の宗教と政治は、すべてこの 40 年を基準に組み直されている。
