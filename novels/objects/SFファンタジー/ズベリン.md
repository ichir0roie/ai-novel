# ズベリン

## 名と、表と裏

| | |
| --- | --- |
| 正式名称 | 夜獸 |
| 通称 | ズベリン |
| 表（住人の理解） | 別の種族 |
| 裏（設定側） | 環境ごとに設計された五系統の一つ |


設定側の名は**夜獸**。

- **何のための設計か** — 森の夜と薄い空気への適応
- **いまの姿** — 毛が濃い。夜目が利く。耳がいい

住人は五系統を互いに別の種族だと思っている。**元は環境ごとに設計された人間である。**
系統をまたいだ子は上限が当てはまらず、魔族になる。
