# さいはい

## ひとこと

| | |
| --- | --- |
| 一言 | 配るものを決める側。自分たちを統治者ではなく勘定係だと思っている |


正式名称は**再配分機構**。誰も正式名称では呼ばない。

「配分」は、ひなたの正式名の最後の一語 Allocation から来ている。
**機械の機能名が、そのまま統治機構の名になった。**
通称のほうは、いつからか「采配」と混ざって書かれるようになった。
**配るための名だったものが、振るうための名として読まれている。**

## 何を配るか

電気。そして電気の上に載っているもの全部——食べるもの、環境の手当て、
遺伝子の手当て、情報体の網、子を持つ権利。

地球に降る日射は固定値なので、取れる総量は動かない。
**一人あたりの暮らし向きは、人の数で割った商になる。**
さいはいの仕事は、その割り算をどう配るか決めることだけである。

## どう動くか

- **選挙で選ばれない。** 計算の合う者が入る
- **戦争を止めない。** 止めないが、資源が減る戦争だけを止める。
  だから戦争は文化として残り、人はあまり死ななくなった
- **自分たちを統治者だと思っていない。** 勘定係だと思っている

この最後の一つが、この組織のいちばん厄介なところである。
悪意がない。**割り算をしているだけ**だという自覚しかない。
数合わせも、入植星への命令も、同じ顔で決めている。

## 言い分

> 我々が管理した 380 年は誰も死ななかった。管理をやめた 270 年で九割が死んだ。

これに反論できる者が、崩壊時代の地球にいない。**それがこの時代の停滞の正体でもある。**

## 制限

- **分子を増やせない。** 地球に降る光は動かせない。できるのは分母をいじることだけ
- **崩壊時代には配るものがない。** まだあるが、配るものが減りつづけている
- 4100 年代以降、機械を作れない。**書けるのは遺伝子だけ**
