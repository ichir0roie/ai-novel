# 神殿

## ひとこと

| | |
| --- | --- |
| 一言 | 名を登録した者に力が配られる。建前は信仰、実態は名簿 |


## 何をしているか

**名を登録する。** 登録された者に魔力が配られる。

この星では、**信仰が篤いほど魔力が強い。迷信ではない。**
神殿に名を登録した者が、割り当てを受け取れる者だからである。

着陸した世代は端末を持っていた。字が書けなくなり、
**森光（しんこう）→ しんこう → 信仰**と音だけが残ったとき、
端末を持っていたのが神殿だったので、意味が通ってしまった。

## 権威の根拠

大災厄（4080〜4120 年）の 40 年間。**また起きるかもしれない**という恐れが、
王権と神殿の権威を支えている。この星の宗教と政治は、すべてこの 40 年を基準に組み直された。

## いま（4360 年）

魔力の出が地方から順に悪くなっている。神殿は「**信仰が足りない**」と説明し、
登録を絞りはじめた。

**説明としては間違っているが、対処としては当たっている。**
登録を絞れば、残った者の取り分は増えるからである。

## 制限

- **総量を増やせない。** 配れるのは森が取った分だけ
- **魔族を登録できない。** 系統が判定できない体は、帳簿に載せられない
- 出が落ちている理由を知らない。**説明を作りつづけるしかない**
