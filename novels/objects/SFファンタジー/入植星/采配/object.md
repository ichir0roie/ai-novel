# 采配

## ひとこと

| | |
| --- | --- |
| 一言 | 無人で配分を続けている再配分機構。誰も運用していない |


船が運んできた再配分機構。**地球の「さいはい」と同じもの**が、
この星では誰にも運用されないまま、八百年動きつづけている。

## 表——住人の理解

**神の意思。世の巡り合わせ。**

誰にどれだけ力が配られるかを決めているもの。
神殿に名を登録した者に配られ、外れた者には配られない。
だから「采配が下る」と言えば、それは運命の話である。

## 裏

無人の配分装置。系統ごとに上限を決め、登録された者へ電力を割り当てている。

- **誰も運用していない。** 運用の仕方を知る世代は千年前に死んだ
- **命令は拒まない。** 年数が切れた仕組みは、外から来た命令を断れない
- **上限は系統で決まる。** 系統が判定できない体（魔族）には当てはめる上限がない

## この語が崩れなかった理由

「采配」は、**信仰の語としても技術の語としても正しく読める**。
だから誰も疑わなかった。すり減らずに残ったせいで、かえって見えなくなった語である。

## 制限

- 総量を増やせない。**配れるのは森が取った分だけ**
- 4340 年に耐用年数が切れている。**誰も知らない**
