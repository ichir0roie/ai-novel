# マデンジ

## 名と、表と裏

| | |
| --- | --- |
| 正式名称 | 坑守 |
| 通称 | マデンジ |
| 表（住人の理解） | 別の種族 |
| 裏（設定側） | 環境ごとに設計された五系統の一つ |


設定側の名は**坑守**。

- **何のための設計か** — 地下の設備を保つ
- **いまの姿** — 頑丈で背が低い。石と金物に強い

住人は五系統を互いに別の種族だと思っている。**元は環境ごとに設計された人間である。**
系統をまたいだ子は上限が当てはまらず、魔族になる。
