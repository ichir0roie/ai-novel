# サールゼメ

## ひとこと

| | |
| --- | --- |
| 一言 | 塩の平原。魔力がいちばん薄く、版図がいちばん広い |


設定側の名は**鹽軛**。巨大な塩の平原。

**塩の平原には森が生えない。魔力がいちばん薄い。**

- 足りない分を武で補った。**魔力の薄い国が、いちばん広い版図を持っている**
- 征服した先の森を押さえ、そこの民を軛につないだ。
  支配層は塩の民、被支配層は森の民
- 塩そのものは売れる。**魔力では負けているが、物では勝っている**
- 三国でもっとも人口が多く、もっとも内側が荒れている

系統がそのまま身分になっている。支配層はトーラン、被支配層はシャンヒル。

## 動き方

**攻めるのは、いつも森である。**
森の出が落ちれば落ちるほど、残った森の価値が上がる。
