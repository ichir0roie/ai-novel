# ヴォルホフ

## ひとこと

| | |
| --- | --- |
| 一言 | 森がいちばん多い国。器の大きい者が治める。王も神殿も要らない |


設定側の名は**澤巫**。湿地と森が大半を占める大陸。

**森がいちばん多い。だから魔力がいちばん濃い。**

- 器の大きい者が治める。**力が測れるので、身分が揺らがない**
- 王も神殿も要らない。**強い者が強いことは、見れば分かる**
- 三国でもっとも「魔法の国」らしく見える。**もっとも何も考えなくて済んだ国**でもある
- 湿地なので農地が少ない。人は少なく、散っている

系統の偏りはシャンヒルとズベリン。森の系統が多い。

## 弱点

考えなくて済んだぶん、**何も蓄えなかった。**
森の出が落ちたとき、この国には代わりに差し出せるものがない。
