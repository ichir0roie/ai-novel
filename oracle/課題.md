## AIのアウトプットと人間のインプット

一気に生成すると人間側の把握速度と、新規情報への理解の抵抗が発生した。
良いストーリー、発想をするには、それぞれのアイデアへの理解が重要だと思うが、人間側が置き去りにされてしまうような。


## トークン足りない。

こういう大量生成を使用するとトークンがすぐに切れてしまうな。ソースコードの改修レベルではない。


claude code maxプランなら十分。
開発がある程度進行した状態であれば、proプランでも足りるかも。

集中してストーリーを書いている間は、ランダム生成ツールは使う必要性もないというか、claudeでインターフェース作ったら思いの外うまく動きやがる。

数話調整をするうちに固定化されてしまった。
