# text
作者が持つ主人公。作者の理想と欲望を詰め込んだ人物像として立てる。
種族は天使だが、体は人間を基にしていて、外部デバイス(外装)は一つも接続していない。
1572年(西暦11572年)、物語の開始と同じ年にエンピレオで生まれ、生後まもなく母ミレアに連れられて地上へ降り、最初の十年を中央大陸ハルディアのヴェルム聖王国で母と二人で暮らす。
そこからノウルを旅して、成長し、出会い、冒険し、社会に影響を与えながら、150年の人生を生きて往生する(1722年、西暦11722年)。

# 肉体

女性を基にした体で、運動性能が高い。跳ぶ・走る・登る・打つが地上の人間族の上限を超え、傷の治りも速い。
両性で、どの性別とも交配できる。相手は肉体を持つ人間ベースの種族なら何でもよい(人間族・エルフ・ダークエルフ・ドワーフ・獣人・魔族・天使)。両性であることは見た目に出ない。
遺伝子改良の血筋で、力は生まれで決まると信じる地上の住人からは「血筋の強い子」として見られる。

# 容姿

背丈168cm、細身で筋肉質。手足が長く、立ち姿がまっすぐ。
髪は白に近い淡い金で、癖のない直毛。幼い頃は短く、長じてからは後ろで一つに結わえる。
瞳は薄い灰青。肌は白く、日に焼けにくい。翼は無い(天上の天使の翼は外装なので、外装を持たないこの人物には無い)。地上では血筋の良い人間族の娘に見える。
手のひらに灯す魔力灯りは色の無い白で、地上のどの血筋にも無い色。これだけが天使であることの外に出る印で、本人は幼いうちはその意味を知らない。
表情がよく動き、笑うと目が細くなる。長じてからは口数が減り、静かに人を見る癖がつく。

# 気質の変遷

性格の欄は、生まれた時点(幼少)の値。
- 幼少(〜15歳): 活発で自由な発想を持ち、危険にも無警戒に関わっていく危うさがある。好奇心と行動力が先に立ち、協調性は低い。
- 青年(15〜40歳): 現実の難しさを理解し、冷静さを獲得していく。一時は欲・悲観・憎しみに流される。誠実性は並から高へ、協調性は低から並へ、行動力は必から高へ寄る。
- 壮年以降(40歳〜): 徐々に理想を手にし、誠実さを持って現実に向き合う人格者になる。誠実性は必、感情表現は並に落ち着く。好奇心と想像力は最後まで下がらない。

# 家族

- 母ミレア(character id=2): 地上での最初の十年を一緒に暮らす。天使の使者として地上に居る建前で、娘に翼が無い理由も、父のことも語らない。
- 父カシル(character id=3): 娘の体を書いた血の書き手。娘が生まれた年に都を追われて地下へ降り、悪魔になる。娘は父を知らずに育ち、のちの旅の過程で悪魔として、敵として出会う。作者が書く。

# 生成側の扱い

生成側はこの人物を作らず、筋書き・出来事も足さない。周りの人物と出来事だけを作る。
本人が知っている年は1572年からの四桁の年で、万の位が落ちていることは知らない。暦の万の位に気づき、世界の本当の年に手をかけるのはこの人物で、それは作者が書く。

# 来歴(誕生〜1572年)

1572年、エンピレオの使者の家に生まれる。父カシルが血の書き手として、リンドールの禁じられた写しにあった「始まりの民の型」で体を書き、外装を繋ぐ口を作らなかった。
届け出の日に裁きの座の帳のどこにも入らず、白い灯りが知れる前に、母ミレアに連れられて生後三月で地上へ降りる。
現状: 生後間もなく、ヴェルム聖王国で母と暮らし始めたところ。何も知らない。
