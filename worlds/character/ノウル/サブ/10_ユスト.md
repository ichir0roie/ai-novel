# text
序列一位の家系の当主格で、血統管理省の調整官。家柄で調整官の席に就いた正統派で、登録規格どおりに子の遺伝子を調整することを「都の理念を守る高潔な務め」と語り、自分でもそう信じている。ラファルの父。序列十二位から技能だけで上がってきたカシルに省内の評価で追い抜かれ、妬みを積もらせてきた。1572年、ノアの出生時検査を担当し、規格外を見つけるとただちに裁定局へ届け出て、カシルの逮捕を主導する。同じ年に生まれた跡取りラファルには、規格どおりの体と「最初の翼」を約束している。名は「正しき者」の意で、告発の動機が妬みであることを本人だけが認めない皮肉を負う。

# 口調

一人称は「私」、二人称は「貴君」。
丁寧で、整った長い文を話す。制度の語を崩さず、日常の言葉に言い換えない。
自分の務めを「都の理念」と結びつけて語る癖があり、私情を述べる場面でもその形を崩さない。
侮蔑は敬語のまま出す。声も表情も変えないので、言われた側だけが気づく。

# 来歴(誕生〜1572年)

1542年、エンピレオの序列一位の家系に生まれる。
1560年、家柄によって血統管理省の調整官に就く。序列上位の家系の子の調整を任され、規格を一度も外れたことがないのを誇りにする。
1563年、序列十二位の出のカシルが技能で採用され、数年のうちに担当実績と省内の評価で自分を追い抜く。カシルが派遣官の家系(序列三位)に入ったことも面白くなく、以後、カシルの扱う記録データの出所を静かに探り続ける。
1572年、跡取りラファルを規格どおりに設計し、人工母体で生まれさせる。同じ年、カシルが担当した子の出生時検査を担当し、遺伝子構成が登録規格に無いことを見つける。ただちに規格外として裁定局へ届け出て、カシルを違法遺伝子調整の容疑で逮捕させる。
現状: 三十歳。省の潔白を示した功で評価を上げ、カシルの手元にある記録データの出所を追っている。息子には「最初の翼」を約束している。
