# text
エンピレオの裁定を司る座。型と序列の帳を持ち、子を型に入れる日と、地上へ降ろす使者と、都から追う者を決める。数の始まりから暦を保ってきたのもここで、地上に万の位を渡さぬことを掟の一つにしている。

# 来歴(誕生〜1572年)

1年(数の始まり)、地上に暦を配り直した年に、エンピレオの裁定を司る座として立つ。それ以前の座の帳は封じられ、リンドールの塔にだけある。
以後千五百年余り、型と序列の帳を持ち、子を型に入れる日と、地上へ降ろす使者と、都から追う者を決めてきた。地上に万の位を渡さぬことを掟の一つにし、使者の役はこの掟を守るためにある。
1400年代、地下パンデムが「開かれた型」を地上へ配り始めてからは、地上の裁定を増やしている。
現状: 型に無い体の子が届けられ、帳のどこにも入れられずに初めて割れた。母子を地上へ降ろし、見張りに妖精をつけたところ。
