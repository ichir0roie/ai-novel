# text
エンピレオの裁定を担う行政機関。家系ごとの遺伝子情報の登録規格と序列の台帳を持ち、子の遺伝子調整と外部デバイス接続の認可、地上への派遣官の任命、追放処分を決める。新典歴の暦を保ってきたのもここで、地上に万の位を渡さないことを規程の一つにしている。

# 来歴(誕生〜1572年)

新典歴0年(数の始まり)、地上に暦を配り直した年に、エンピレオの裁定機関として設置される。それ以前の記録は封鎖され、リンドールの塔にだけある。
以後千五百年余り、登録規格と序列の台帳を持ち、子の遺伝子調整の期日と外部デバイスの接続認可、地上へ降ろす派遣官、追放処分を決めてきた。地上に万の位を渡さないことを規程の一つにし、派遣官の任務はこの規程を守るためにある。
1400年代、地下パンデムが「開放型」(登録に無い遺伝子データ)を地上へ配り始めてからは、地上への裁定通達を増やしている。
現状: 出生時の検査で登録規格に無い遺伝子構成の子が届け出られ、台帳のどこにも登録できずに初めて意見が割れた。裁定官アウレアが廃棄処分を裁定したが、母ミレアの抗議で中止し、規格外として保留登録した上で監視役の妖精をつけたところ。

# plot

起: 登録規格に無い遺伝子構成の子が届け出られ、台帳のどこにも登録できずに初めて意見が割れる。規格外として保留登録し、監視役の妖精をつける。
承: 1576年、血統管理省からの報告で調整官カシルの禁止技術の研究が明らかになり、追放処分を決める。母ミレアの願い出を受け、処分として長期の地上派遣を負わせて母子ともに地上へ降ろす。白い灯りの子が都に居ないことで瑕疵の声を抑える。
転: リンドールに記録の封鎖を求め、子を巡る都の記録を消しにかかる。地上から「天の子」の噂が上がってきて、加護の兆しと取る派と瑕疵と取る派が局の中で対立する。
結: 1582年、十歳の接続審査で外部デバイスを接続しないと決定し、母だけを召還して子を地上の台帳の外に置く。不認可の前例が局の中に亀裂として残る。
