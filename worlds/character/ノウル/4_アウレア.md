# text
派遣官の家系の家長で、ミレアの母。六十年にわたり家の序列を三位に保ってきたことを誇りにし、遺伝子情報の登録規格と序列こそが文明崩壊から都を守ったと信じている。孫娘の白い灯りを、家系記録の瑕疵として見ている。

# 来歴(誕生〜1572年)

1480年、派遣官の家系に生まれる。当時の家の序列は五位。
1512年、家長を継ぐ。以後六十年、裁定局への縁と派遣任務の実績を積み上げ、家を三位まで上げた。
1540年、娘ミレアを産む。夫は1550年に地上派遣の任務中に失われ、以後は一人で家を保つ。
1565年、娘と序列の下の出のカシルとの縁組を、技能を買って認める。
現状: 九十二歳。規格外の孫を家系記録の瑕疵として見て、血統管理省に届け出て外部デバイスを早期接続させるよう娘に求めているが、娘は拒んでいる。
