# text
ローザ諸都市同盟で生まれ育った人間族の女。ノアより五歳年下。幼い頃からの悪友であり、のちに旅を共にする冒険者となる。

# 容姿
赤い髪、ツリ目。日焼けした肌で、細身だが鍛えられている。飾り気のない身なりを好む。

# 性格
活発で物怖じせず、人形遊びや装いより、剣ごっこや木登りのような荒っぽい遊びを好む。一度決めたことは曲げない実直さがあり、ノアへの憧れと対抗心が入り混じった感情を抱き続ける。

# 来歴
11577年、ローザ諸都市同盟で誕生。
11584年(七歳)、友人と遊ぶノア(十二歳)に突っかかったのが初対面。女なのに男勝りに振る舞い、男子とも自然に仲良く遊ぶノアが気に入らなかった――それまで親の言いつけに従って女の子らしく振る舞い、我慢していた反動だった。結局その場は、ノアの機転で一緒に遊ぶことになる。
11587年(十歳)、ノアの背を追って冒険者になることを志す。
11592年(十五歳)、冒険者になり、街を飛び出す。
11593年(十六歳)、旅から戻ったノアと再会し、以後は一党に加わる。

# 未来
ノアとの間に娘を一人もうける。出産後、いったん戦線を離れるが、体力を取り戻して再び参戦する。
ザハラ全土を巻き込む紛争のさなか(11593〜11603年)、カシルの護衛の攻撃からノアを庇って死亡する。この死が、カシルとノアの間に決定的な確執を残し、11603年のパンデムでの対峙につながる。
