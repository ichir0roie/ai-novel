# text
シルヴァーンの大森林から出てきたエルフの女。魔術器具を操って後衛を務める。十九歳のときローザでノアと出会い、以後、ノアが死ぬまで離れない。

# 容姿

エルフとしては異例に発育が早く、里では体つきだけが先に育った子として浮いていた。
ノアと出会った十九歳の頃は外見が人間の十五歳ほどで、街の子どもたちに混ざって遊んでも誰も不審に思わなかった。
二十代に入ると起伏のはっきりした体つきになり、つばの広い三角帽子を被るようになる。背丈169cm。

# 性格

怠慢。理由も事情も無く、ただ単純に動くのが億劫なだけ。
ところがその緩慢さと無口さが、周囲には「時間の流れの違う神秘的なエルフ」として映る。里にいた子どもの頃から、黙って座っているだけで敬われるこの誤解の恩恵を受け続けてきた。本人は訂正しない。

# 戦い方

魔力そのものではなく魔術器具で戦う。器具はローザの闇市を通じて地下から流れてきたもので、出所は本人も詳しく知らない。
体ひとつで戦うノアとは、力の在り処が正反対にある。

# 口調

一人称は「わたし」、二人称は「あなた」。
間延びしてのんびり。返事が一拍遅れ、その遅れが周りには思慮深さに見える。本人は面倒なだけ。
文が短く、語尾を伸ばす。否定も肯定も「……うん」で済ませることが多い。
誤解されたまま敬われることに慣れていて、訂正しない。黙っているのが最も省力だから。

# 来歴

11567年、シルヴァーンに生まれる。ハイエルフの末裔を自任する里の気風になじめないまま育つ。
11586年(十九歳)、ローザ諸都市同盟へ流れ、十四歳のノアと出会う。

# 未来

数百年の寿命を持ち、仲間を一人ずつ見送る側に回る。11663年にラウロを、11722年にノアを看取る。
以後もアルバの代の物語に主要人物として残る。
