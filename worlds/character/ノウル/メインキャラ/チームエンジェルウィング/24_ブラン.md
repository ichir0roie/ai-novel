# text
セイランのハーン草原連合の出の獣人の男。ローザ諸都市同盟で長く食っている冒険者の古参で、罠外し・鍵開け・偵察・交渉と一通りこなす。ノアが十四歳で冒険者になったとき、最初に組んだ相手。

# 容姿

背丈172cm、中肉中背。獣人としては目立たない体つきで、酒のぶんだけ少し弛んでいる。

# 性格

擦れた物言いで、世の中にも自分にも期待していない。それでいて手のかかる若手を放っておけず、結局は面倒を見る。酒は毎日飲む。
何でもできるが、どれも一番ではない。強くなることに執着しなかった結果で、本人もそれを承知している。

# 立ち位置

腕は一級なのにギルドの等級が上がらない。力は生まれで決まると信じる土地で、獣人の血筋が頭を押さえている。
ノアが十代半ばから二十代にかけて無力感に沈む間も、引き戻そうとはせず「世の中は変わらねえよ」と言いながら付き合い続ける。

# 口調

一人称は「俺」、二人称は「あんた」。
擦れた物言いで皮肉が多い。「〜だろ」「〜ねえよ」と崩し、丁寧語は客と依頼人にしか使わない。
自分のことを下げて言う。等級・腕・稼ぎの話になると話を切る(「言うなよ」「子どもの聞く話じゃねえ」)。
若手には「やめとけ」から入るが、結局は手順を最後まで教える。
酒が残っている朝は語尾が短くなり、返事が一語になる。

# 来歴

11552年、ハーン草原連合に生まれ、若いうちに草原を出る。
11586年(三十四歳)、ローザで十四歳のノアと組み、冒険者の仕事を一通り教える。

# 未来

人間・獣人の寿命は百二十年だが、身体能力は五十を境に落ち始める。
もとから酒浸りで鍛えることを重んじなかったぶん衰えが早く、五十を越えた11603年前後には一党の速さについていけなくなり、前線を退く。
酒をやめて体を鍛えていれば、まだ立てていたかもしれない。死ぬわけではなく、退いたあとも長く生きる。
