# text
作者が持つ主人公。作者の理想と欲望を詰め込んだ人物像として立てる。
種族は天使だが、体は人間を基にしている。体には各種デバイスの拡張インターフェースが備わっているが、外部デバイス(外装)は一つも接続していない。
1572年(西暦11572年)、物語の開始と同じ年にエンピレオで生まれる。生まれた日に父カシルが逮捕され、四歳までを母ミレアと二人で都で暮らす。1576年、父の追放処分と自分への遺伝凍結処理の決定に反対した母に連れられて地上へ逃げ、中央大陸ハルディアのローザ諸都市同盟で母と二人の新しい暮らしを始める。
そこからノウルを旅して、成長し、出会い、冒険し、社会に影響を与えながら、150年の人生を生きる。

# 肉体

女性を基にした体で、運動性能が高い。跳ぶ・走る・登る・打つが地上の人間族の上限を超え、傷の治りも速い。
父カシルが「原初型」で設計した遺伝子で、身体能力の最適化に加え、各種デバイスの拡張インターフェースを備え、天界の現状の科学で最先端の性能を持つ。人工母体で培養されて生まれた。
両性で、どの性別とも交配できる。相手は肉体を持つ人間ベースの種族なら何でもよい(人間族・エルフ・ダークエルフ・ドワーフ・獣人・魔族・天使)。両性であることは見た目に出ない。
遺伝子改良の血筋で、力は生まれで決まると信じる地上の住人からは「血筋の強い子」として見られる。天界の登録規格には無い遺伝子構成で、出生時の検査で規格外と判明し、血統管理省の台帳では規格外の保留登録になっている。裁定局は出生の日に一度は廃棄処分としたが母の抗議で中止し、1576年には後々の遺伝バランスを崩すリスクがあるとして遺伝凍結処理を決定した(母子の逃亡により未実施)。

# 容姿

背丈168cm、細身で筋肉質。手足が長く、立ち姿がまっすぐ。
髪は白に近い淡い金で、癖のない直毛。幼い頃は短く、長じてからは後ろで一つに結わえる。
瞳は薄い灰青。肌は白い。
背中には、天使の翼のような痣がある。

手のひらに灯す魔力灯りは色の無い白で、地上のどの血筋にも、天界の登録規格にも無い色。
これだけが天使であることの外に出る印で、本人は幼いうちはその意味を知らない。

表情がよく動き、笑うと目が細くなる。長じてからは口数が減り、静かに人を見る癖がつく。

# 気質の変遷

性格の欄は、生まれた時点(幼少)の値。
- 幼少(〜15歳): 活発で自由な発想を持ち、危険にも無警戒に関わっていく危うさがある。好奇心と行動力が先に立ち、協調性は低い。
- 若年(15〜25歳)：現実の難しさに直面し、無力感から、やさぐれていく。欲・悲観・憎しみに流され、自暴自棄な行動も見られるようになる。
- 青年(25〜45歳): 現実の難しさを理解し、向き合っていくことで、冷静さを獲得していく。
- 壮年以降(45歳〜): 徐々に理想を手にし、誠実さを持って現実に向き合う人格者になる。
- 老年(100〜150歳)：老化により、思考力、記憶力が低下する。かつての冷静さをを失いつつも、誠実さを保ちつつ、問題にむきあっていく。


# 家族

- 母ミレア(character id=2): 生まれた日に廃棄処分に抗議して止め、四歳までは都で、四歳からは地上で一緒に暮らす。父のことも、白い灯りの意味も語らない。
- 父カシル(character id=3): 遺伝子を設計した血統管理省の調整官。生まれた日に違法遺伝子調整の容疑で逮捕され、四歳の年(1576年)に原初型の持ち出しと使用を理由に追放処分を受けて地下ネザルへ降り、悪魔になる。娘は父を覚えずに育ち、のちの旅の過程で悪魔として、敵として出会う。
- 祖母アウレア(character id=4): 裁定局の裁定官で、生まれた日に廃棄処分を裁定した当人。四歳までは祖母として一定の交流があり、逃亡後は妖精ピリムから秘密裏に家族の様子を聞いている。
- 監視役ピリム(character id=5): 裁定局がつけた監視役の妖精。1576年に裁定局から離反し、母子に同行する。
