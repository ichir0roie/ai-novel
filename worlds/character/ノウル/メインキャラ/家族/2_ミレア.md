# text
エンピレオの裁定局に仕える派遣官の家系に生まれ、地上へ降りて裁定局の通達を伝える派遣官の任務を務めた天使。
地上では「天使の使者」として扱われる。降りるたびに地上の「混じる」暮らしを見て帰り、報告書には書かない。
主人公の母で、娘の遺伝子構成が登録規格に無いことを出生の日に知っている。
出生の日、裁定局(裁定官である母アウレア)が娘を廃棄処分と裁定したのに抗議して中止させ、以後は自分の手で親子として育てる。
1576年、夫カシルの追放処分に合わせて娘への遺伝凍結処理が決まると、これに反対して四歳の娘を連れて地上へ逃げ、中央大陸ハルディアのローザ諸都市同盟で新しい暮らしを始める。

# 性格

物静かで言葉数が少なく、言うときは言い切る。感情はほとんど表に出さない。
裏表は無く、地上の人間ともひっそりと友好関係を築くが、家にも局にも従順ではない。
道徳のためなら家も任も捨てる、強い意志を持つ。

# 来歴(誕生〜1572年)

1551年、エンピレオの派遣官の家系(序列三位)に、家長アウレアの娘として生まれる。
幼い頃から、序列の下の家系の子カシルと友人として育ち、長じて恋愛関係になる。家長は反対したが、カシルの技能が家の役に立つとして黙認している。

1569年、十八で初めて地上派遣の任務に就き、ヴェルム聖王国に裁定局の通達を伝える。1571年にも派遣され、二度の任務で地上の「混じる」暮らしを見て帰った。報告書には書かない。

カシルが逮捕されたとき、抗議をしに向かったが、アウレアに連れ戻され、ノアの裁定に同行する。
そこでノアを娘として育てることを決意し、引き取ることになる。

娘と生活する間、拘束されたカシルの養護をするも、裁決はかわらず、カシルは追放される。
その間、面会時にカシルからノアの特異性について知る。

地上に降りた後、娘を守るため、地上の住人の助けを借りながら、生き延びていく。

# 未来

時折、天使特有の能力(高速移動、高火力の兵器)を活用し、娘の旅路を支援するが、基本は地上に構えた住処で大人しく旅を見守る。(遠視で)

娘が21歳になって帰ってきたあと、カシルと会ったことを聞く。カシルの目的の危うさに、悲壮な決意をし、旅に同行することを決意する。

10年後、カシルとノアの戦いに決着がつく。ミレアは、死にゆくカシルの隣で涙ながらに思いを口にし、ノアとともにパンデムを後にする。

# plot

起: 登録規格に無い遺伝子構成(両性で、どの血筋とも交配できる)の娘が生まれ、血統管理省に届け出るか隠すかを迫られる。家長の母アウレアは届け出て外部デバイスを早期接続させよと言う。
承: 娘を届け出るが外部デバイスの接続は拒み、夫カシルが娘の遺伝子を設計したと知って夫を庇う。四年を都で娘と暮らし、拘束された夫との面会を重ねながら、娘の特異性を知っていく。
転: 1576年、夫が追放処分を受け、同時に娘への遺伝凍結処理が決まる。任を願い出る道を取らず逃亡を選び、四歳の娘を連れて地上へ降りて、中央大陸ハルディアのローザ諸都市同盟に住処を構える。監視役の妖精ピリムは裁定局を離反して同行する。
結: 地上では人間族の母子として暮らし、娘には翼が無い理由も父のことも語らない。娘の白い灯りは人目から隠させるが、それでも漏れた分が「天の子」の噂として街に流れる。娘が冒険者になり、十八で旅に出てからは住処に留まり、遠視と天使の力で遠くから見守る。
