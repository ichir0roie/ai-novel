# text
序列の下の家系から技能で血統管理省に上がった天使の調整官。家系の遺伝子情報どおりに子の遺伝子を調整する役だが、リンドールの閲覧禁止区画にあった「原初型」(移民当初の未改変の遺伝子データ)の複製を持ち出し、自分の娘の遺伝子をその型で設計した。設計した体には外部デバイスの接続口を作らなかった。主人公の父。1576年、禁止技術の研究を理由に追放処分を受けて地下ネザルへ降り、パンデムで悪魔になる。娘とは、娘の旅の過程で悪魔として、敵として出会う(作者が書く)。

# 来歴(誕生〜1572年)

1534年、エンピレオの序列の下の家系(十二位)に生まれる。家に役職は無く、幼いうちから記録データを読むことだけが得意だった。
1552年、技能を認められて血統管理省に採用され、序列の下の出として初めて子の遺伝子調整を担当する資格を得る。
1560年頃、リンドールとの記録データの貸借を担当し、塔の閲覧禁止区画から「原初型」の複製を一件、返却せずに手元に留めた。
1565年、派遣官の家系のミレアと結ばれ、家に入る。
1572年、娘の遺伝子を原初型で設計し、人工母体で培養した。外部デバイスの接続口は作らなかった。
現状: 三十八歳。娘の白い灯りの原因を省に問われ始め、データの出所を隠している。妻と娘と三人で都に暮らしている。
