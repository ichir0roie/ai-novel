# text
エンピレオの裁定局に仕える派遣官の家系に生まれ、地上へ降りて裁定局の通達を伝える派遣官の任務を三度務めた天使。地上では「天使の使者」として扱われる。降りるたびに地上の「混じる」暮らしを見て帰り、報告書には書かない。主人公の母で、娘の遺伝子構成が登録規格に無いことを出生の日に知っている。1576年、夫カシルの追放処分に伴い、長期の地上派遣を願い出て四歳の娘を連れて地上へ降り、ヴェルム聖王国で六年を娘と二人で暮らす。

# 来歴(誕生〜1572年)

1540年、エンピレオの派遣官の家系(序列三位)に、家長アウレアの娘として生まれる。
1558年、十八で初めて地上派遣の任務に就き、ヴェルム聖王国に裁定局の通達を伝える。1563年と1568年にも派遣され、三度の任務で地上の「混じる」暮らしを見て帰った。報告書には書かない。
1565年、序列の下の家系から上がった調整官カシルと結ばれる。家長は反対したが、カシルの技能が家の役に立つとして認めた。
1572年、娘が生まれる。出生の日に、娘の遺伝子構成が登録規格に無いことを知る。
現状: 三十二歳。娘を血統管理省に届け出たが、外部デバイスの早期接続は拒み、生後三月の娘と夫と三人で都に暮らしている。
