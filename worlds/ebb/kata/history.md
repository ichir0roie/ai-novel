# 潟の歴史

暦は〈**退き潮の暦**〉（潟暦）。起点は内海が退いた年。

## 年表

| 潟暦 | 出来事 |
| --- | --- |
| 0 年 | 内海が退き、いまの低地が現れる。四種族が別々にこの年を記憶している |
| 〜120 年 | 低地への移住。穂の民が書字によって土地を切り拓き、他三種を「保護」する枠組みができる |
| 150 年頃 | 第五の陸〈書原〉が書字の中心地になる。最も多く書かれ、最も豊かな土地だった |
| 200〜480 年 | 書原の全盛期。書字による灌漑、建築、収穫の操作。〈枯れ〉は「書けば直せる」と信じられていた |
| 430 年頃 | 書原の外縁で回復しない枯れが広がりはじめる。合議は書字量の制限を議論したが、決まらなかった |
| **510 年** | **空から火が降り、書原が割れて沈む。** 数十万が死ぬ。四種族すべてが目撃した |
| 511〜560 年 | 「書きすぎた罰」という解釈が定着。**書字制限令**。書ける土地を合議が割り当てる制度になる |
| 600 年頃 | 磐の民が刻字の法的承認を求める。却下。以後 200 年、同じ要求が繰り返されている |
| 690 年 | 低潟で淀の民の大規模な離村。枯らされた土地を捨てた。歌にだけ記録が残る |
| 780 年頃 | 「書けない穂」が問題として語られはじめる。特権はあるが土地がない世代 |
| 810 年 | 前回の十四合議。書字割当の見直しが提案され、先送りされた |
| **812 年** | 現在。**〈遅〉が満ちる年**。十四合議の年にあたる |

## 火の年（潟暦 510 年）をめぐる問題

- 穂の民の記録: 「書きすぎた咎により、天が書原を裁いた」
- 磐の民の刻字: 「火は西から来た。書原の上ではなく、空の全体が光った」
- 淀の民の歌: 「二度光った」と歌う節がある。穂の民の記録には一度としか書かれていない
- 渡の民: 記録を残していない。ただし口伝で「あの日、鳥が一斉に落ちた」と言う

**書かれたほうが勝つ**ので、公式には「書きすぎた罰」である。
だがこの星の誰も、火が本当に罰だったのかを知らない。

> 〈灰洲〉では同じ日、伴星が光って地表が焼けた。両星のどちらも、それを知らない。
> 詳細は `worlds/ebb/world.md`。**作中で明かさないこと。**

## 〈枯れ〉の現状

- 書原以外にも、回復しない枯れが低地に点在している。〈**死に地**〉と呼ばれる
- 死に地は年 0.3% ほど増えている。合議はこの数字を公表していない
- 書字割当は 5 年ごとに縮小されている。表向きの理由は「土地の保全」
- 本当の理由を知る者は、合議の書記だけ
