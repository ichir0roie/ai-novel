# 潟の歴史

暦は**かた暦**。起点は内海が退いた年。

## 年表

| かた暦 | 出来事 |
| --- | --- |
| 0 年 | 内海が退き、いまの低地が現れる。四つの種族が、別々にこの年を覚えている |
| 〜120 年 | 低いところへの移住。穂の民が書きで土地を拓き、他の三種を「預かる」枠組みができる |
| 150 年頃 | 五つめの陸〈書原〉が書きの中心地になる。最も多く書かれ、最も豊かな土地だった |
| 200〜480 年 | 書原の全盛。書きによる水引き、普請、実りの手入れ。〈枯れ〉は「書けば直せる」と信じられていた |
| 430 年頃 | 書原のへりで、戻らない枯れが広がりはじめる。寄り合いは書きの量を減らす話をしたが、決まらなかった |
| **510 年** | **空から火が降り、書原が割れて沈む。** 数十万が死ぬ。四種族すべてが見た |
| 511〜560 年 | 「書きすぎた罰」という解釈が定まる。**書き止め**が定められ、書ける土地は寄り合いが割り当てるものになる |
| 600 年頃 | 磐の民が、刻んだものを掟の上で認めるよう求める。退けられる。以後 200 年、同じ求めが繰り返されている |
| 690 年 | 下潟で淀の民の大きな離村。枯らされた土地を捨てた。歌にしか記録がない |
| 780 年頃 | 「書けない穂」が問題として語られはじめる。特権はあるが土地がない世代 |
| 810 年 | 前回の大寄り合い。書き割りの見直しが出たが、先送りされた |
| **812 年** | 現在。**〈おそ〉が満ちる年**。大寄り合いの年にあたる |

## 火の年（かた暦 510 年）をめぐる問題

- 穂の民の記録: 「書きすぎた咎により、天が書原を裁いた」
- 磐の民の刻み: 「火は西から来た。書原の上ではなく、空の全部が光った」
- 淀の民の歌: 「二度光った」と歌う節がある。穂の民の記録には一度としか書かれていない
- 渡の民: 記録を残していない。ただし口伝で「あの日、鳥が一斉に落ちた」と言う

**書かれたほうが勝つ**ので、公には「書きすぎた罰」である。
だがこの星の誰も、火が本当に罰だったのかを知らない。

> 〈シオヒ〉では同じ日、伴星が光って地表が焼けた。両星のどちらも、それを知らない。
> 詳しくは `worlds/ebb/world.md`。**作中で明かさないこと。**

## 〈枯れ〉のいま

- 書原のほかにも、戻らない枯れが低いところに点々とある。〈**死に土**〉（しにつち）と呼ぶ
- 死に土は年に 0.3% ほど増えている。寄り合いはこの数字を公にしていない
- 書き割りは五年ごとに減らされている。表向きの理由は「土地を守るため」
- 本当の理由を知っているのは、寄り合いで書く者だけ
