# シオヒの社会

## 延べ人と延べなし

単一の種だが、社会は**〈延べ〉を受けたか否か**で二分されている。

| | 〈**延べ人**〉（のべびと） | 〈**延べなし**〉 |
| --- | --- | --- |
| 寿命 | 約 142 年 | 約 40〜55 年 |
| 人口比 | 約 2 割 | 約 8 割 |
| 条件 | 高いボンドを長く保ち続けること | 受けられない |
| 見た目 | 受けた年齢で止まる。ただし髪と爪から色が抜ける | 普通に老いる |

俗に、延べなしのことを〈**みじか**〉と呼ぶ。本人の前では使わない。

**世代交代が止まっている。** 要職は 100 年以上おなじ人間が占め、
延べなしは自分の一生のあいだ、一度も上が入れ替わるのを見ない。

〈延べ〉の副作用は公表されていないが、現場では知られている:

- 新しいことを覚えにくくなる。古い記憶ほど鮮やかで、直近ほど薄い
- 40 年を超えたあたりから、痛みと味が鈍る
- 稀に、受けた年の出来事を「昨日のこと」として話しはじめる者が出る

## ボンド

この星の権限のすべて。

- 個人に紐づく点数**ではない**。「誰が、あなたのどの行いを保証したか」の**履歴**
- 保証した側は、相手が裏切れば自分のボンドも削れる。だから保証は重い
- ボンドがなければ、水も薬も延べも買えない。売る側が保証を求めるため
- ボンドを失うことを〈**切れる**〉という。切れた者は北笠を出て、外れ衆へ行くか塩原へ出る

記録所はボンドを発行しない。**記録して、参照させるだけ**。それで統治になっている。

> 注意: これはステータス画面ではない。数値は本人にも見えない。
> 自分のボンドがどうなっているかは、他人の態度からしか知れない。

## 四つの勢力

| 名称 | 所在 | 性格 |
| --- | --- | --- |
| **記録所**（正式には北笠記録所） | 北笠 | ボンドの記録を握る事実上の政府。自分を政府と呼ばない。延べ人が要職を占める |
| **外れ衆**（はずれしゅう） | 北笠のへり | ボンドを拒む集落の緩い集まり。血縁と年齢が権限の根拠。延べなしが多く、寿命が短い |
| **南笠の郷**（さと） | 南笠 | 唯一の農地を持つ。ボンドを輸入したが独自に運用し、記録所と絶えず揉めている |
| **ハシゴ** | 軌道 | 人口 3 万に満たない。古仕掛けの掘り返しと売却を独占。地表の三者すべてに売るため中立を装う |

食料は南笠が握り、記録は記録所が握り、機械は〈ハシゴ〉が握る。外れ衆は何も握っていない。
**この偏りが、この星の政治のすべて。**

## 名前

姓を持たない。二〜三音のカタカナ名に、所属や保証者を添えて区別する。

- 北笠: 名＋「誰が結んだか」。例「**トウ**、記録所のミサキ結び」
- 外れ衆: 家の名が先に来る。例「**ハタ家のシノ**」
- 南笠: 畑や職の名を添える。例「**ユキ**、三番畑の」
- ハシゴ: 番号と通り名。本名を名乗らない文化がある。例「**九番**」

## 言葉

- 「**切れる**」= ボンドを失う
- 「**掘る**」= 古仕掛けを掘り出す／転じて、他人の過去を調べる
- 「**まだ見てる**」= 火の年を見た者である、の意。半ば侮蔑を含む
- 「**薄い**」= 直近の記憶が曖昧な延べ人を指す。面と向かっては使わない
