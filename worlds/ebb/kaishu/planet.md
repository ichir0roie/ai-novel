# 惑星〈灰洲〉（かいしゅう）

## 一言で

赤い塵の空の下、両極の二つの陸だけに人が住む重い星。
死ななくなった人間たちが、自分たちが失くした技術を掘り返して暮らしている。

## 空気感

重い。乾いている。埃っぽい。腕を上げるのが少し億劫な重力。
明るい場面でも空は赤く、白い光はどこにもない。

## 天文

| 項目 | 値 |
| --- | --- |
| 主星 | 〈環〉（かん）。橙寄りの安定した星 |
| 伴星 | 〈芯〉（しん）。白色矮星。肉眼では昼でも見える鋭い点 |
| 重力 | 1.6 G |
| 1 日 | 29.5 標準時間 |
| 1 年 | 600 灰洲日 |
| 現在 | 退潮暦 300 年 |
| 人口 | 約 4 億 2000 万 |

〈芯〉は 111 年前（退潮暦 189 年）に一度だけ強く光った。**火の年**。
それ以来、天文を扱う者は〈芯〉を見張り続けているが、次があるかどうかは誰にもわからない。

## 地理

高重力ゆえに大気は濃く、焦帯から巻き上がる塵が常に上空を流れている。空は赤い。

| 区分 | 内容 |
| --- | --- |
| 〈**焦帯**〉（しょうたい） | 赤道をはさむ帯。砂と熱。人は住まない。旧文明の残骸が埋まっている |
| 〈**上冠**〉（じょうかん） | 北の居住域。人口の六割。信証制度の本場 |
| 〈**下冠**〉（げかん） | 南の居住域。やや温暖で、この星で唯一の農地がある |
| 〈**塩原**〉（しおはら） | 606 年前に極海が退いた跡。両冠の内側に広がる白い平原。歩けるが何も育たない |
| 軌道 | 前世代が残した構造物の残骸が帯になって回っている |

移動は主に**地下**か**塩原の上**。塵のせいで空路は限られ、飛行機械は高価で、
長距離の空移動そのものが権限の象徴になっている。

## 生活の手触り

- 建物は低く、天井が低い。1.6 G では高い建物も高い家具も要らない
- 人は背が低く、脚が太く、歩幅が小さい。転倒は骨折を意味する
- 屋外に出るときは口と目を覆う。塵は吸えば肺に残る
- 水は塩原の地下から汲む。塩を抜く設備を持つかどうかが集落の格を決める
- 食事は薄い。下冠から来る乾燥穀物と、地下で育てる藻。味は誰も期待していない

## この星で起こりやすい物語

- 死なない人間と、死ぬ人間のあいだの断絶
- 自分の記憶と、公式の記録が食い違ったとき、どちらを信じるか
- 掘り返した技術を「理解せずに使う」ことの後ろめたさ
- 18 年前に届いた〈外音〉が何だったのか、誰も答えを持っていない

## 書かないと決めたこと

- 前世代文明がなぜ滅びたか（火の年だけが原因かどうか）は確定させない
- 〈外音〉の発信源。最後まで明かさない
- 星の裏側、焦帯の底に何が埋まっているか。噂だけ残す
