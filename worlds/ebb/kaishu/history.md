# 灰洲の歴史

暦は**退潮暦**。起点は極海が退いた年。それ以前の記録は断片しかない。

## 年表

| 退潮暦 | 出来事 |
| --- | --- |
| 0 年 | 極海が退き、塩原が現れる。生き延びた集団が両冠に定住。暦がここから数えられる |
| 〜80 年 | 上冠・下冠でそれぞれ都市が成立。相互の往来はほぼない |
| 80〜150 年 | 前世代文明の全盛。軌道構造物、継続処置、大気制御。記録はこの時代が最も多く、最も信用されていない |
| 170 年頃 | 〈環〉と〈芯〉の観測記録に異常が出はじめる。当時これを重大視した者はいない |
| **189 年** | **火の年。**〈芯〉が光る。焦帯が焼け、軌道構造物の大半が落ちるか砕ける。人口が三分の一に減る |
| 190〜230 年 | 「灰の四十年」。技術の連鎖的な喪失。作り方がわからないまま機械だけが残った |
| 231 年 | 上冠で最初の**信証**が発行される。物も食料もない中で、「誰を信じるか」だけが取引可能な資産だった |
| 240 年頃 | 軌道の残骸から前技（前世代技術）の掘り返しが始まる。〈梯〉の前身が生まれる |
| 258 年 | 継続処置が再現される。**ただし作った者たちは原理を理解していない** |
| 265 年 | 冠央信証機構が上冠の実質的な統治者になる。選挙も革命もなかった |
| 271 年 | 旧領同盟が信証を拒否して分離。以後、緩い緊張が続く |
| **282 年** | **〈外音〉受信。** 焦帯の観測塔が、外から来た信号を拾う。灰笛と同じ周波数を含んでいた。三日で止んだ |
| 283〜現在 | 外音をめぐる解釈の対立が続く。機構は「自然現象」と公式に結論した |
| **300 年** | 現在 |

## 火の年をめぐる問題

平均寿命は 142 灰洲年。**火の年から 111 年しか経っていない。**

つまり、あの日を見た人間が、まだ何万人も生きている。

- 機構の公式記録は「〈芯〉の閃光は約 40 秒」としている
- 目撃者の証言は「数分続いた」「二度光った」「音がした」で一致しない
- 目撃者どうしも一致しない。記憶は 111 年で変質する

**記録は書き換えられたのか、記憶が壊れたのか。** この星では、これが政治問題になる。

機構は「人間の記憶は 100 年を超えると信用できない」という立場を取り、
継続者の証言能力に制限をかけようとしている。当然、継続者たちは反発している。

## 前技（ぜんぎ）について

火の年以前の技術。軌道の残骸や焦帯の埋没施設から掘り出される。

- **動くが、理由がわからない。** 修理はできるが改良はできない
- 継続処置も前技のひとつ。副作用の全容は誰も把握していない
- 前技を掘る者は信証を得やすい。逆に、掘った物を隠すと信証を失う
- 「使っていいのか」を問う声は常にあるが、使わない選択肢は現実的でない
