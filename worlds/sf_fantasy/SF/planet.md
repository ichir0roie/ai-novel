# 惑星〈潟〉（かた）

## 一言で

標高がそのまま身分になった段々の星。
文字を書けるのは一つの種族だけで、書くたびに土地が死ぬ。

## 空気感

軽い。湿っている。緑が濃く、下へ行くほど濃い。
声がよく通る。0.9 G の空気は薄く澄み、遠くの音が近くに聞こえる。

## 天文・暦

| 項目 | 値 |
| --- | --- |
| 重力 | 0.9 G |
| 1 日 | 19 標準時間（短い） |
| 1 年 | 344 日 |
| 月 | 二つ。〈**はや**〉21.5 日で一巡り／〈**おそ**〉約 5 年で一巡り |
| 暦 | 〈はや〉の一巡りが 1 月。16 月で 1 年。**かた暦 812 年** |
| 人口 | 約 2 億 3000 万 |

一日が短いので、潟の民は**一日に二度眠る**。昼の短い眠りを〈**中伏せ**〉（なかぶせ）という。
月が短く年が長いので、「何月か」で話す習慣がなく、「〈はや〉が何度巡ったか」で数える。

〈おそ〉が満ちるのは 5 年に一度。この年の祭りと裁きだけが、
十四の寄り合いすべてに共通する時間の物差しになっている。

## 地理 —— 高さがすべて

いま残っている陸は四つ。すべて段々になっていて、高さの差が極端。

| 陸 | 特徴 |
| --- | --- |
| 〈**大棚**〉（おおだな） | 最大。麓から頂まで 4000 m 超。十四の寄り合いのうち九つがここにある |
| 〈**二牙**〉（ふたきば） | 尖った二つの山。寄り合いは三つ。土が痩せていて、書きはほとんど行われない |
| 〈**沈み残り**〉 | 書原が割れたときに残った岸。寄り合いは一つ。瓦礫と落とし物の土地 |
| 〈**下潟**〉（しもがた） | いちばん低く、大半が湿地。寄り合いは一つ。淀の民の本拠 |
| 〈**書原**〉（かきはら） | **302 年前に割れて沈んだ五つめの陸。** いまはない。最も文字が使われた土地だった |

高さで暮らしが変わる。

- **低いところ（〜300 m）**: 土が肥えている。ただし〈枯れ〉が最も出やすい。淀の民と、穂の民の書き場
- **中ほど（300〜1500 m）**: 段々畑と町。人の大半がここにいる。渡の民が上下をつなぐ
- **高いところ（1500 m〜）**: 痩せた岩場。磐の民。ここでは誰も書かない。**書ける土地がない**

「**下の者**」「**上の者**」は方角ではなく身分を指す。**下ほど豊かで、下ほど危うい。**

## 〈書き〉

文字を書くと、書かれたとおりのことが起きる。

- 文字は〈**元音**〉（もとね）の形だとされる。元音を聞くと、生き物は一瞬止まる
- 書けるのは**穂の民だけ**。他の三種が同じ形を書いても、ただの線になる
- 刻む・彫る・織るでは起きない。**流れるもので、面に書く**必要がある

### 代償は二つ

1. **土地が痩せる**（〈**枯れ**〉）。書いた場所を中心に、土から力が抜ける。
   一度枯れた土地は二代、三代は戻らない。大きく書くほど広く枯れる
2. **書いた者が失う**。穂の民は自分の体の水を墨にする。書けば書くほど渇き、味を失い、
   老いが早く来る。長く書いた者は、水を飲んでも渇きが取れなくなる

### だから

**書くことは特権であり、加害である。** 誰の土地を枯らして書くのかが、いつも揉め事になる。
掟も約束も歴史も、書かれたものだけが効く。そして書けるのは穂の民だけ。

> 注意: 等級も属性も呪文の一覧もない。何をどう書けば何が起きるかは整理されていない。
> 穂の民のあいだでも「効く書き方」は家ごとの秘密で、互いに教えない。

## 書かないと決めたこと

- 元音が何なのか。誰が最初に文字を作ったのか
- 書原が沈んだ本当の理由（「書きすぎた罰」は彼らの解釈にすぎない）
- 〈おそ〉の正体
