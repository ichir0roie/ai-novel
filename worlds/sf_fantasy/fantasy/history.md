# シオヒの歴史

暦は**引き暦**（ひきごよみ）。起点は極海が退いた年。それ以前の記録は断片しかない。

## 年表

| 引き暦 | 出来事 |
| --- | --- |
| 0 年 | 極海が退き、塩原が現れる。生き延びた集団が両笠に定住。暦がここから数えられる |
| 〜80 年 | 北笠・南笠でそれぞれ都市ができる。行き来はほとんどない |
| 80〜150 年 | 技術の全盛期。軌道の構造物、延べ、大気の手入れ。記録はこの時代が最も多く、最も信用されていない |
| 170 年頃 | 〈親〉と〈子〉の観測記録に妙な数字が出はじめる。当時これを重く見た者はいない |
| **189 年** | **火の年。**〈子〉が光る。焼け帯が焼け、軌道の構造物の大半が落ちるか砕ける。人口が三分の一に減る |
| 190〜230 年 | 「灰の四十年」。技術が連鎖的に失われる。作り方がわからないまま機械だけが残った |
| 231 年 | 北笠で最初の**ボンド**が結ばれる。物も食料もない中で、「誰を信じるか」だけが取引できる資産だった |
| 240 年頃 | 軌道の残骸から古仕掛けの掘り返しが始まる。〈ハシゴ〉の前身が生まれる |
| 258 年 | **延べ**が作り直される。**ただし作った者たちは理屈をわかっていない** |
| 265 年 | 記録所が北笠の実質的な統治者になる。選挙も革命もなかった |
| 271 年 | 外れ衆がボンドを拒んで分かれる。以後、緩い緊張が続く |
| **282 年** | **〈ソトネ〉受信。** 焼け帯の観測塔が、外から来た信号を拾う。止まり音と同じ高さの音を含んでいた。三日で止んだ |
| 283〜現在 | ソトネをめぐる解釈の対立が続く。記録所は「自然の現象」と公式に結論した |
| **300 年** | 現在 |

## 火の年をめぐる問題

この星の長命者の寿命は 142 年。**火の年から 111 年しか経っていない。**

つまり、あの日を見た人間が、まだ何万人も生きている。

- 記録所の公式記録は「〈子〉の光は約 40 秒」としている
- 見た者の証言は「数分続いた」「二度光った」「音がした」で一致しない
- 見た者どうしも一致しない。記憶は 111 年で変わる

**記録が書き換えられたのか、記憶が壊れたのか。** この星では、これが政治になる。

記録所は「人の記憶は 100 年を超えると当てにならない」という立場を取り、
延べ人の証言の重みに制限をかけようとしている。当然、延べ人たちは反発している。

## 古仕掛け（ふるじかけ）について

火の年より前の機械。軌道の残骸や、焼け帯に埋まった施設から掘り出される。

- **動くが、理屈がわからない。** 直せるが、良くはできない
- 延べも古仕掛けのひとつ。副作用の全部は誰も把握していない
- 古仕掛けを掘る者はボンドを得やすい。逆に、掘った物を隠すとボンドが切れる
- 「使っていいのか」と問う声は常にあるが、使わないという選択肢は現実的でない
