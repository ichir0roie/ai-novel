# 惑星〈シオヒ〉

## 一言で

赤い塵の空の下、両極の二つの陸だけに人が住む重い星。
死ななくなった人間たちが、自分たちで失くした技術を掘り返して暮らしている。

名は「潮が干た土地」の意。606 年前に極海が退き、そこから暦が始まった。

## 空気感

重い。乾いている。埃っぽい。腕を上げるのが少し億劫な重力。
明るい場面でも空は赤く、白い光はどこにもない。

## 天文

| 項目 | 値 |
| --- | --- |
| 主星 | 〈**親**〉（おや）。橙寄りの安定した星 |
| 伴星 | 〈**子**〉（こ）。白色矮星。昼でも見える鋭い点 |
| 重力 | 1.6 G |
| 1 日 | 29.5 標準時間 |
| 1 年 | 600 日 |
| 現在 | 引き暦 300 年 |
| 人口 | 約 4 億 2000 万 |

〈子〉は 111 年前（引き暦 189 年）に一度だけ強く光った。**火の年**。
以来、空を見る仕事の者は〈子〉を見張り続けているが、次があるかどうかは誰にもわからない。

## 地理

重力が高いので大気は濃く、焼け帯から巻き上がる塵が常に上空を流れている。空は赤い。

| 区分 | 内容 |
| --- | --- |
| 〈**焼け帯**〉（やけおび） | 赤道をはさむ帯。砂と熱。人は住まない。古い時代の残骸が埋まっている |
| 〈**北笠**〉（きたがさ） | 北の居住域。人口の六割。ボンドの本場 |
| 〈**南笠**〉（みなみがさ） | 南の居住域。やや温暖で、この星で唯一の農地がある |
| 〈**塩原**〉（しおはら） | 606 年前に極海が退いた跡。両笠の内側に広がる白い平原。歩けるが何も育たない |
| 軌道 | 火の年より前の世代が残した構造物の残骸が、帯になって回っている |

移動は主に**地下**か**塩原の上**。塵のせいで空路は限られ、飛ぶ機械は高く、
長い距離を空で移動できること自体が身分の証になっている。

## 生活の手触り

- 建物は低く、天井が低い。1.6 G では高い建物も高い家具も要らない
- 人は背が低く、脚が太く、歩幅が小さい。転ぶことは骨折を意味する
- 外へ出るときは口と目を覆う。塵は吸えば肺に残る
- 水は塩原の地下から汲む。塩を抜く設備を持てるかどうかが集落の格を決める
- 食事は薄い。南笠から来る乾いた穀物と、地下で育てる藻。味は誰も期待していない

## この星で起こりやすい物語

- 死なない人間と、死ぬ人間のあいだの断絶
- 自分の記憶と、公式の記録が食い違ったとき、どちらを信じるか
- 掘り返した機械を「理屈がわからないまま使う」ことの後ろめたさ
- 18 年前に届いた〈ソトネ〉が何だったのか、誰も答えを持っていない

## 書かないと決めたこと

- 火の年より前の文明がなぜ滅びたか（火の年だけが原因かどうか）は確定させない
- 〈ソトネ〉の発信源。最後まで明かさない
- 焼け帯の底に何が埋まっているか。噂だけ残す
