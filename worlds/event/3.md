# text
谷から吹き下ろす風は夜になるほど冷たくなった。フィノは詰所と前線を何度も往復して、革靴の底がすり減った気がした。伝えることは毎回同じだ。物資はどこまで届いたか、退路はどこが塞がれているか、次の交代はいつか。

北の谷の岩陰に伏せる隊員たちの間を抜けて、フィノはコルの姿を探した。すぐに見つかった。地面に片膝をついて、木の枝で土に線を引いている。配置の見直しだ。もう何度目かわからない。

「コルさん、詰所から伝令です。西の道、まだ塞がってます」

コルは顔を上げずに頷いた。枝で線を一本足す。

その手の動きに、フィノは引っかかりを覚えた。いつもより遅い。振り下ろす角度も浅い。

「コルさん、その腕」

コルは枝を止めた。

「なんでもない」

「布、血で真っ黒じゃないですか」

左腕に巻かれた布は、もとの色がわからないくらい濃く染まっていた。コルはそれを右手で隠すように動かしたが、隠しきれるものではなかった。

「かすっただけだ」

「かすっただけでそんな色になりますか」

コルは答えずに立ち上がった。ふらつきはしなかったが、立ち上がる動きが一拍遅れた。フィノはそれを見逃さなかった。

「下がってください。手当てしないと」

「今は無理だ」

「無理じゃないです。今夜も見回りに出るんですよね。その腕で剣振れますか」

コルはフィノを見た。今までなら、そこで黙らせる目だった。フィノもよく知っている目だ。でも今日は、フィノは目をそらさなかった。

「僕、伝令で何度もここ来てます。コルさんの判断、今日はいつもより一拍遅いです。二回、気づきました」

コルは何も言わなかった。

「疲れてて、血も失ってて、それで夜の森に出たら、見えるものも見えなくなります。そしたら隊のみんなも危ないです」

「…お前に何がわかる」

「わかりません。でも、これまで何回もコルさんの後ろについて見てました。今日のコルさんは、いつもと違います」

風が吹いて、岩陰の枝葉が鳴った。コルは布を巻いた腕をもう一度見て、それから黙った。長い沈黙だった。フィノは動かずに待った。

「…手当てする」

コルは短く言った。

「わかった。でも指揮は」

「詰所に。お前が報告持ってこい。俺はここで手当てしながら聞く」

フィノは一瞬、自分の耳を疑った。

「僕がですか」

「他に誰がいる」

コルはもう歩き出していた。フィノは慌ててついていく。

◇

岩陰の奥、隊員が簡易の手当てを施す間、コルは腰を下ろして目を閉じていた。布を解くと、傷は思ったより深かった。爪でえぐられたような傷口が、腕の内側まで走っている。隊員が水で洗い、新しい布を巻き直す間、コルは声を漏らさなかった。

フィノはその間、伝令として動き回った。西の道の状況、隊員の配置、翌朝の交代の順番。ひとつひとつ確認して、コルのところへ戻って報告した。

「西の道、隊員二人で塞いでます。交代は夜明けに」

コルは目を開けて聞いていた。

「東は」

「東は問題ないです。でも夜になったら唸り声、増えるかもしれません」

「なら東にもう一人回せ」

「わかりました」

フィノは頷いて、また駆け出す。何度目かの往復のあとで、隊員の一人が声をかけてきた。

「フィノ、お前がコルさんの代わりに指示出してるのか」

「代わりじゃないです。報告してるだけです」

「充分代わりだろ」

フィノは何と答えていいかわからずに、頭を掻いた。でも悪い気はしなかった。

手当てが終わって、コルは腕を軽く曲げてみせた。まだ痛むはずだが、顔には出さなかった。

「明日からも、こうやって報告してくれ」

「はい!」

「調子に乗るなよ」

「乗ってません」

コルはわずかに口の端を上げた。笑ったところをフィノは初めて見た気がした。

森の奥からまた低い唸り声が聞こえてくる。数はまだ減っていない。村の守りはまだ終わらない。でも、フィノはさっきまでとは違う場所に立っている気がした。伝令として走るだけじゃない。自分の見たものを、自分の言葉で伝える。それがコルに届いた。

夜の見回りの時間が近づいていた。フィノはもう一度、西の道の様子を確かめに駆け出した。
