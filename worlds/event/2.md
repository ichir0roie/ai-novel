# text
境界沿いの土は、乾いているのに妙な匂いがした。獣の匂いだ。それも一匹二匹じゃない。コルは朝の見回りでその匂いを嗅ぎ取ってから、ずっと胸の奥に小さな棘が刺さったような感じを抱えていた。

詰所に戻ると、フィノが待ち構えていた。

「コルさん、今日の依頼ってどんなのですか! 討伐? それとも見回りだけ?」

コルは答えずに水を飲んだ。フィノは新米で、ここに来てまだ日が浅い。何を聞いても目を輝かせる。

その時、村の方から馬が駆けてくるのが見えた。土埃を上げて詰所の前で止まると、鞍から転げ落ちるように早馬の男が降りてきた。

「コルさん! 大変です、ここ数日で魔物の数が、普段の何倍にも!」

男は息を切らしながら言った。コルは黙って男の顔を見た。目の下の隈、汗、震える手。嘘や大げさで言っているのではない。

「どこから」

「北の谷から森にかけて全部です。羊が三頭やられて、畑も荒らされて…」

コルは表情を変えずに聞いていたが、目だけが鋭くなった。今朝嗅いだ匂いはこれだったのか。

「わかった」

短くそれだけ言うと、コルは詰所の壁にかけてある地図の前に立った。指で村の位置と森の境目をなぞる。

「配置を厚くする。持ち場周辺、全員こっちに回せ」

隣にいた隊員が頷いて動き出す。コルは早馬の男に向き直った。

「村には、今夜は外に出るなと伝えろ」

「はい、はい!」

男は再び馬に飛び乗って戻っていった。

フィノがそばに寄ってきた。さっきまでの浮ついた顔ではなく、少し緊張した顔つきになっている。

「僕も行きます」

コルはフィノを見た。

「実力、足りてないだろ」

「わかってます。でも、荷物運びでも、伝令でも、何でもやります。足手まといにはならないようにします」

コルはしばらく黙っていた。フィノの目は逃げていない。

「…離れるな。俺の後ろにいろ」

「はい!」

フィノは大きく頷いた。

◇

支度をしていると、馬車が一台、詰所の前に止まった。降りてきたのはエルミナだった。供の者を二人連れている。急な話とは思えないほど、身なりも足取りも落ち着いていた。

「コル様、急なお話とは存じますが」

エルミナは丁寧に頭を下げた。

「今の急報、耳に入りました。村々への物資の融通、それと護衛の人手、うちの店で用立てることができます」

コルは荷を背負いながら、視線だけをエルミナに向けた。

「かわりに」

「辺境の警備隊との継続的な取り決めを一つ、結ばせていただければと」

コルは手を止めなかった。荷紐を締め直しながら言う。

「今はそれどころじゃない」

「ですが、人手が足りないのは事実でしょう。物資も」

「村が先だ」

それだけ言うと、コルは背負った荷を担ぎ直して馬の方へ歩き出した。エルミナは追わなかった。かわりに、静かな声で言った。

「では、条件のお話は、また日を改めて」

コルは振り返らずに答えた。

「好きにしろ」

エルミナは口元にわずかな笑みを浮かべた。断られたとは思っていない顔だった。供の者に何か目配せすると、馬車に戻る前に一言だけ付け加えた。

「辺境の皆様が無事でいらっしゃることを、お祈りしております」

馬車が土埃を上げて去っていくのを、フィノが物珍しそうに見ていた。

「あの人、商家の人ですよね。ここまで来るなんて」

「気にするな」

コルは馬に乗り、手綱を握った。

「今夜から、しばらく詰所に戻れない日が続く」

フィノも慌てて自分の馬に乗った。

「僕、頑張ります」

「頑張るだけじゃ死ぬぞ」

コルは短くそれだけ言うと、馬の腹を蹴った。フィノも慌ててあとを追う。

北の谷に向かう道の先、木々の向こうから低い唸り声が聞こえてくる。数が増えている、というのは本当らしい。コルは腰の剣に手をかけたまま、目だけを森の奥に向けた。今日から、しばらくこの持ち場は普段の顔をしない。
