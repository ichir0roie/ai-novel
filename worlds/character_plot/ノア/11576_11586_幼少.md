# text
1576年、四歳で母ミレアと地上のヴェルム聖王国に降り、母が天使の使者として神官たちに奉られる横で、人間族の子として育つ。翼が無い理由も、父のことも聞かされない。
活発で自由な発想を持ち、川へ飛び込み、塀を登り、市場の外れまで行きたがる。監視役の妖精ピリムと遊び、ピリムは報告書から都合の悪いことを抜き始める。
白い灯りを見た神官が「天の子」と噂を広げ、噂は都の裁定局にも届く。

1582年、十歳。エンピレオの接続審査で外部デバイスの接続は不認可と決まり、母だけが都に召還される。母は戻るとは言わずに昇り、祖母アウレアから預かった灯し方の一枚と、地上の暮らし方だけを残す。ピリムは裁定局の連絡員を解かれるが、体が無いので追い払えず、影に住みついたまま離れない。

1582年から1586年、母のいないヴェルム聖王国で神官たちの元に残され、人間族の子として暮らす。「天の子」の噂と、自分だけが持つ白い灯りの意味を知らないまま、十四歳になる。
