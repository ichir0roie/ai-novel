# 世界観: 白い年（仮称）

<!-- 宇宙名は仮。作者が別案を出したら git mv で差し替える -->

## 一言で

ひとつの地球から分かれた星々が、空の同じ方向にある同じ影を見ている宇宙。

## 空気感

明るく、乾いていて、寒い。滅びたあとの世界ではなく、**滅びを避けつづけた末の世界**。
豊かさが行き渡っていて、誰も飢えていない。そのために何を差し引いたかを、誰も勘定していない。

## 核となるルール

1. **白い年**: 暦の起点。空が一度だけ白く染まった年。どの星もこの年を 0 年として数える
   - 制限: **白い年より前の一次資料が、どの星にも残っていない。** 原初の時代の話は、すべて写しの写し
2. **空の影**: どの星からも、空の同じ方向に説明のつかない影が見える
   - 制限: 見えるだけ。近づいた者の記録が一つもない。観測は自由、到達は不能
3. **植民の断絶**: ひとつの星が他の星を植民した過去がある。いまは行き来がない
   - 制限: 技術的に不可能なのか、禁じられているのかが、どちらの側でも判然としない

## 力の構造

星ごとに違う。共通するのは一つだけ——**どの星でも、配る者が支配している。**
配るものが資源なのか、土地なのか、寿命なのか、力なのかが星ごとに変わる。

- 誰が不満を持っているか: 配られる側。ただし配られる側は飢えていない。
  **不足ではなく、配られること自体が火種になる**

## 時代背景

- **暦**: 白い年を 0 年とする。それ以前は西暦で記す
- **原初の時代**: 西暦 3000 年ごろの地球 → `地球/history.md`
- 白い年が西暦何年にあたるかは**未定**

## この世界で起こりやすい物語

- **自分たちの豊かさの出どころを知ってしまう話。** 誰も悪人でなく、誰も無関係でもない
- **同じ影を見ている二つの星が、互いを知らないまま同じ結論にたどり着く話**
- **配る側に回ってしまった者の話。** 配る権利を持った瞬間、数合わせと同じ顔になる

## 書かないと決めたこと

- 空の影の正体。**両方の物語が終わっても明かさない**
- 白い年に何が起きたか。星ごとに違う言い伝えを置くだけにする
- 地球以外の星の数。必要になったときに増やす
