# 乱数ログ / 白い年

`core/principles.md` に従い、引いた目とシードを全部残す。
**解釈**の欄には、出た語そのものではなく「どう読んだか」を書く。

## 宇宙の骨格

```
python3 tools/roll.py --prefix 宇宙/ --seed 20260918
```

| テーブル | 出た目 | 解釈 |
| --- | --- | --- |
| 星間の関係 | 一方が他方を植民した過去がある | 地球が植民した側。いまは断絶 |
| 両星に共通する異常 | 空の同じ方向に説明のつかない影がある | ほぼそのまま採用。二つの物語をつなぐ唯一の糸にする |
| 暦の起点 | 空が一度だけ白く染まった年 | 「白い年」。宇宙名にも流用した |

三つとも噛み合ったので調整なし。

## 原初の地球

```
python3 tools/roll.py --table SF/人類の状態 --table SF/政体の主流 --table SF/社会の緊張 --table SF/技術到達点 --seed 771203
```

| テーブル | 出た目 | 扱い |
| --- | --- | --- |
| 政体の主流 | 技術官僚制 | そのまま →「配り所」。作者の「戦争や経済は調整され」の主語になった |
| 社会の緊張 | 労働が不要になった後の生の意味 | そのまま採用 |
| 人類の状態 | 大半が意識のみで存在 | **読み替え。** 意識の移し替えではなく「体を置いて情報側で暮らす」。作者の「遺伝子技術で健康は維持された」と衝突させないため。結果、健康は誰も歩かせていない体のために保たれていることになった |
| 技術到達点 | 他所から来た技術を理解せずに使っている | **作者の「代理のエネルギー生成法を生み出した」と正面衝突。** 捨てず、争点として保留（→ `地球/history.md` 争点 1）。作者の判断待ち |
