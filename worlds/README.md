# worlds

世界観ごとの設定。**1 ディレクトリ = 1 宇宙**。1 つの宇宙を複数の作品で共有する。

```
worlds/<universe-id>/
  world.md          宇宙全体の設定（暦・共通現象・星どうしの関係）
  rolls.md          乱数ログ。引いた目とシード、調整の理由
  glossary.md       固有名詞の一覧。表記ゆれ防止
  <planet-id>/
    planet.md       天文・地理・空気感
    history.md      年表と、歴史をめぐる争点
    society.md      種族・国家・制度
    characters/     登場人物
    objects/        アイテム・組織・場所の個別設定
```

## 原則

- **物語に必要な分だけ作る。** 使われない設定は書かないほうがいい
- **制限を書く。** 能力には必ず代償か制限を設ける。制限のない設定は物語を殺す
- **同じ宇宙の中では矛盾を許さない。** 暦・物理法則・共通現象は星をまたいで一致させる
- **宇宙どうしの矛盾は平行宇宙として許容する。** 別の `worlds/<id>/` は直さない
- **本文で生まれた設定は必ずここへ書き戻す**
- **固有名詞は `glossary.md` に登録する**
- **名づけは日本語として自然に。** 音読み二字熟語の造語を重ねない（`core/naming.md`）
- **アバウトな要素は乱数で決める。** `core/tools/roll.py`。引いた目は `rolls.md` に全部残す
