# ひなた

<!-- 石油に代わる発電法。フィクション科学時代の土台であり、崩壊時代の原因 -->

## 名

| | |
| --- | --- |
| 正式名 | Heliotropic Integrated Network for Autotrophic Transduction and Allocation |
| 略称 | H.I.N.A.T.A. ／ **ひなた** |
| 日本語での言い換え | 半永久継続型太陽光エネルギー変換機構 |
| 命名 | 2300 年代。開発側が頭文字から取り、そのまま日常語になった |

最後の一語が **Allocation**（配分）であることが、のちに効く。
統治機構の正式名称「**再配分機構**」（通称 **さいはい**）は、
この機械の最後の一語から取られている。

## 何をするものか

太陽光を取り、電気に変え、人のところまで運ぶ。それだけ。

地球の外から来るエネルギーのうち、人が当てにできるのは日射だけだった。
ひなたの発明は「新しいエネルギーを見つけた」のではなく、
**降ってくる光を、放っておいても取り切れるようにした**という一点にある。

- **自己修復する。** 壊れた分を自分で作り直す。材料は据わっている地面から取る
- **手がかからない。** 据えたら、あとは人が触らなくていい
- **止まらない。** 光が届くかぎり、線の先には電気が来ている

フィクション科学時代の地球人は、**電気の出どころを知らないまま三百年暮らした。**
知らなくても困らなかったから。

## 施設

ひなたは仕組みの名であって、建物の名ではない。実物は普通の施設として建っている。

| | 正式名称 | 通称 |
| --- | --- | --- |
| 光を取る場所 | 太陽光発電所 | **ひなた場**（ひなたば） |
| 電気を配る場所 | 配電所・変電所 | 配電所（そのまま） |

**ひなた場**は一か所ずつ番号で呼ばれる。生物型のひなた場は建物ではなく、
森か苔の原にしか見えない。**それでも書類の上では発電所である。**

## 二つの型

| | 機械型 | 生物型 |
| --- | --- | --- |
| 出た順 | 先（2300 年代） | 後（2500 年代〜） |
| 出力 | 高い | 低い |
| 自己修復 | 部品の入れ替え。人手が要る | 自分で治る。人手が要らない |
| 敷く速さ | 据えれば即日 | 年単位で広がる |
| 見た目 | 板と管 | 森か、苔か、珊瑚のようなもの |

自己修復を突き詰めた末に、生物型が生まれた。
安く、広く、遅い。**世代をまたいで面積を増やしていくので、誰も敷いた覚えがない。**

崩壊時代に残っているのは生物型ばかりである。機械型は直す人手が先に尽きた。

## 制限

**ここがこの世界の背骨。** ひなたには代償がない代わりに、天井がある。

1. **降る光は増やせない。** 地球に届く日射は固定値。
   ひなたがどれだけ優秀でも、**取れる総量はそこで止まる**
2. **地面を占める。** 敷いた面積は、食うものを作る面積でも、住む面積でもなくなる。
   生物型は材料を地面から取るので、敷いた下は痩せる
3. **光が減ると、全部が同時に止まる。** 環境の手当ても、遺伝子の手当ても、
   おもても、すべてひなたの上で動いていた。**単一の落とし穴**

### 1 と 2 が「収支が閉じた」の正体

フィクション科学時代の地球は、**割り算をしていた**。

- 分子＝地球に降る光のうち、ひなたが取れる分。**動かせない**
- 分母＝人の数
- 商＝一人あたりの暮らし向き

**先に商を決めた。** 資源を潤沢に使える暮らしを基準に据えると、分母が出る。
それが 10 億だった。**80 億でも生きられた。決めた暮らし方で生きられるのが 10 億だった。**

数合わせは人口政策ではない。**割り算の答えを、答えのほうから合わせにいった作業である。**

### 3 が崩壊時代

3630 年、破片が空を覆って分子が落ちた。分母は落ちない。

- 電気が減る → 環境の手当てが止まる → 空気と土が崩れる
- 同じ日に、食べるものも、留守の体を守る仕組みも止まっている
- **敷き直せない。** ひなたは光で自分を直す。光が来ないところでは、ひなたも治らない

崩壊時代の地球でひなたが死んでいくのは、**故障ではなく餓死**である。

## 崩壊時代のひなた

生物型が、暗い空の下で枯れていく速度でしか、まだ滅んでいない。
人の暮らしは、まだ生きているひなたの周りに寄っている。
**可住域とは、いまだに光を取れているひなた場の周りのことである。**

さいはいがまだ存在しているのは、配るものが残っているからではなく、
**どのひなた場が何を出しているかを知っている者が、ほかにいないから。**
