# 入植星 / 解釈表

<!-- 表（ファンタジー）と裏（SF）の対応。この星の設計はすべてこの表を通す -->

## 方法

**裏が土台。表はその不十分な理解。** 順番を逆にしない。

1. ファンタジーの定番を並べる
2. 一つずつ、裏の土台で説明できるか試す
3. **説明できないものは切る。** 残ったものだけが、この星にある
4. 表の物語では、裏の語を一切出さない。**繋がるのは最終盤だけ**

## 土台（これで説明できないものは切る）

船が運んできたのは五つだけ。千数百年たって、**使い方を知る者がいなくなった**。

| | 何か | いまの状態 |
| --- | --- | --- |
| 1 | **生物型ひなた** | 地表を覆っている。住人は「森」と呼ぶ |
| 2 | **ひなたの網と情報体** | 動きつづけている。死んだ者が落ちてきて溜まったまま |
| 3 | **再配分機構（さいはい）** | 無人で配分を続けている。**誰も運用していない** |
| 4 | **遺伝子技術** | 五系統の設計。体の維持機能も生きている |
| 5 | **着陸船と地下設備** | 動かない。埋まっている |

**この五つの外にあるものは、どんなに絵になっても置かない。**

### 代償

| 表の語 | 住人の理解 | 裏の正体 |
| --- | --- | --- |
| 呪い | 人に不幸を与える術 | 他人の割り当てを削る指定 |
| 契約 | 何かと約束して力を得る | 権限の付与。**期限がある** |
| 旧い契約の期限切れ | 世界が終わるという古い言い伝え | 耐用年数の到来。**表の物語を暗くしていく時限** |
| **生贄** | 命を捧げると力が増す | **人が一人減れば、分母が減る。残りの取り分が増える** |

**生贄がこの星でいちばん重い。** これは迷信ではなく、本当に効く。
効く理由は、地球で数合わせが効いた理由とまったく同じである。
**同じ割り算が、片方では政策、片方では儀式になっている。**

## 切るもの

| 切るもの | 理由 |
| --- | --- |
| 転移・瞬間移動 | **情報は飛ぶが物は飛ばない。** 土台のどこにも物質転送がない |
| 飛行魔法 | 同上。人を浮かせる機構がない（0.75 G の滑空、大型飛行生物は可） |
| 異界召喚 | 呼ぶ先がない。手足を呼び寄せるのは可 |
| 時間操作・巻き戻し | 説明不能 |
| 異世界転移・転生（別世界から） | 土台に該当物なし。`core/principles.md` の禁止事項でもある |
| 無からの物質創造 | 材料が要る。**材料ありの合成は残す** |
| 竜人・悪魔・天使 | **五系統の外に知性体を足すと土台が壊れる。** 敵は人間か、ひなたの手足にする |
| ~~魔族~~（復活） | 当初は切ったが、**系統をまたいだ人間**と定義し直したので土台に収まった。外から来た種族ではない |
| 意志を持つ神 | 応答する装置はある。**意志を持つ存在は置かない** |
| 完全な不死 | 長命は残す。死なない体は残さない |
| 四肢の即時再生 | 医療としての治癒は残す。生やし直しは切る |
| ステータス・レベル・鑑定 | `core/principles.md` で禁止済み |

**切った理由を必ず一行で書く。** 後から「やっぱり入れたい」と思ったとき、
土台のどこを壊すことになるかが分かるようにしておく。

## 表の物語の書き方

**ファンタジー側の本文に、裏の語を一つも出さない。**

- 「森」と書く。ひなたとは書かない
- 「魔力が尽きた」と書く。割り当てとは書かない
- 「神が応えた」と書く。自動応答とは書かない
- 住人は正しく困り、正しく喜ぶ。**作者だけが理由を知っている**

読者が裏に気づくのは最終盤でよい。
**それまでは、ただのよくできたファンタジーとして読めること**が条件。

## 語の摩耗

**方法は決まった。音を残して字を付け替えるか、既存の言い回しに紛れ込ませる。**
崩しが浅いと早くバレる。だから**裏の語をそのまま残さない**。

| 裏の語 | 表での形 | 崩し方 | 状態 |
| --- | --- | --- | --- |
| 森光（しんこう） | **信仰** → 力そのものは**魔力** | 音に別の字。意味が通ってしまった | **確定** |
| ひなた | **森** | 名前ごと失われた。呼び名が残らないのがいちばん安全 | **確定** |
| さいはい（再配分機構） | **采配** | 表では字を「采配」で統一する。**読者は慣用句として読み飛ばす** | **確定** |
| 情報体 | **霊体** | 同じものの別名。**通称らしく崩さない**。技術語と信仰語が同じ形をしている | **確定** |
| 端子・無線 | **器**（うつわ） | 入植星に機械の端子はない。**体に生えたものだけ**。「器が大きい」がそのまま通る | **確定** |

**采配と霊体は、崩さないことで隠れている。**
表の読者には信仰の語に見え、裏の読者には技術の語に見える。同じ二文字が二度働く。
